「LINE運用代行に頼みたいけど、費用が読めない」
「A社は月3万円、B社は月30万円。同じサービス名なのに、この差は何なのか」

見積もりを並べた瞬間、こう感じていないでしょうか。

先に結論をお伝えします。LINE運用代行の費用は、**初期構築費10万〜50万円／月額運用費3万〜30万円**のレンジに収まるケースが大半です。そして価格が5倍以上ひらく理由は、業者の良し悪しではありません。任せる範囲の広さが違うだけ。だから比べるべきは総額ではなく、「毎月いくら払って、何が返ってくるか」。金額を横並びにして安い順に選ぶと、まず失敗します。

## LINE運用代行の費用は「3つの形態」に分けて比べる

各社の料金表が噛み合わないのは、性質の違う3つの費用が1枚の表に混ざっているからです。分けて並べ直せば、そこで初めて比較の土俵に乗ります。

1. 初期構築費：アカウント開設、リッチメニュー制作、あいさつメッセージやステップ配信のシナリオ設計など、最初の一度だけ発生する費用
2. **月額運用費**：配信の企画・原稿制作・配信実務・数値分析・改善など、毎月継続して発生する費用
3. 成果報酬：友だち追加数や予約件数など、あらかじめ決めた成果指標に応じて追加で発生する費用

| 費用形態 | よく見る価格帯 | 何に対して払っているか |
| --- | --- | --- |
| 初期構築費 | 10万〜50万円 | 設計・制作の一括作業（一度きり） |
| 月額運用費 | 月3万〜30万円 | 配信制作・分析・改善の継続作業 |
| 成果報酬 | 月額＋αの併用型が中心 | 成果指標に応じた変動分 |

では、3つのうちどれを最優先で見るべきか。発注後の満足度をいちばん左右するのは、月額運用費です。初期構築費は一度払えば終わり。月額のほうは、契約が続くかぎり毎月出ていきます。年間で見ると、月額5万円の契約は初期構築費40万円を上回ります。

見るべきは初期費用の桁ではなく、毎月の出方。ここを取り違えたまま契約すると、1年後に「思っていたより高くついた」となります。

:::memo{title="価格帯の見方について"}
上記のレンジは、複数の比較メディアが公開している料金表に共通して現れる範囲です。業種・地域・依頼範囲によっては、ここから外れる見積もりも出てきます。あくまで「桁感の目安」として使ってください。
:::

## 見落としやすいのは「代行費用の外側」にかかるお金

見積書に載っていない固定費が、毎月かならず出ていきます。LINE運用の総コストは、代行費用だけでは計算できません。

- LINE公式アカウントのプラン料金：LINEヤフーが公開している料金表では、コミュニケーションプラン月0円（無料メッセージ200通）／ライトプラン月5,000円（5,000通）／スタンダードプラン月15,000円（30,000通・超過分は1通あたり最大3円、通数が増えるほど単価が下がる従量制）※いずれも税別
- 外部ツールの利用料：Lステップなどの拡張ツールを使う場合、その月額システム利用料が別途かかります
- 広告費：友だちを広告で集める場合は、当然ながらこれも別枠です

つまり、代行費用は総コストの一部。見積書とは別に、もう一枚の請求書が毎月立っていると考えてください。

:::point{title="友だちが増えるほど、配信の固定費も増える"}
LINE公式アカウントの料金は配信通数課金です。友だち1,000人に月4回配信すれば月4,000通。友だちが5,000人になれば、同じ配信頻度で月20,000通になり、プランのアップグレードは避けられません。**「友だちが増えたら固定費も上がる」**。これを最初から予算に入れておいてください。
:::

## 価格が変わる5つの要因

見積もりが数倍ひらく理由は、次の5点に集約されます。相見積もりを取るなら、この5つを先に揃えて聞く。そこまでやって、ようやく比較が成立します。

1. 任せる範囲：配信の代行だけか、戦略設計・セグメント設計・数値分析・改善提案まで含むか
2. 配信頻度と制作物の量：月2回のテキスト配信と、月8回のリッチメッセージ制作込みでは工数が数倍違う
3. ツール構築の難易度：Lステップなどでシナリオ分岐・タグ設計・流入経路分析まで組むと、初期構築費は上振れする
4. 業種と商材単価：来店型の店舗と、高単価商材のスクール・BtoBでは、必要なシナリオの深さが違う
5. 担当体制：専任のディレクターがつくか、複数社を掛け持ちするオペレーターが配信だけ回すか

裏を返すと、**安い見積もりの多くは「不当に安い」のではなく、単に範囲が狭い**だけです。問題は、範囲が狭いことに気づかないまま契約してしまうことにあります。

迷ったら「この金額で、毎月誰が何を考えてくれるのか」で線を引いてください。

## 安すぎる業者に共通する3つの落とし穴

価格の安さそのものは、悪ではありません。ただし月1万〜3万円台の運用代行を検討するなら、次の3点だけは必ず確認してください。

- 設計がなく「配信代行」だけ：送る作業は代わってくれるが、誰に何を送るかは自社で考える必要がある。実務の負担はほとんど減らない
- 制作物が都度オプション課金：リッチメニュー1枚◯円、画像1点◯円と積み上がり、請求書の総額は当初の見積もりを大きく超える
- レポートが「送信数の報告」で終わる：開封率・クリック率・ブロック率と、そこから何を変えるかの提案がないと、改善は起きない

もうひとつ見落とされやすいのが**最低契約期間**です。LINE運用は成果が出るまで2〜3か月かかるため、3〜6か月の縛りを設ける会社が目立ちます。縛りそのものは合理的な設計。ただし「解約条件」と「途中で範囲を変更できるか」だけは、契約前に文面で確認しておいてください。

:::warn{title="逆に、高い＝良いとも限りません"}
月30万円のプランでも、実態が「月2回の配信＋定型レポート」なら割高です。判断基準は金額の高低ではありません。支払う金額に対して、毎月どれだけの意思決定と手数が動くか。見るべきはそこだけです。
:::

## 費用対効果：月額をLTVで回収する計算例

「払った後に、本当に成果が出るのか」——検討中の不安は、最後にここへ集まります。ただ、この判断は感覚でやるものではありません。**月額を何人分の粗利で回収できるか**、割り算ひとつで出ます。

美容サロン（客単価10,000円・粗利率60%）が月額5万円で運用を依頼した場合の例です。

| 項目 | 数字 |
| --- | --- |
| 月額運用費 | 50,000円 |
| 平均客単価 | 10,000円 |
| 粗利率 | 60% |
| 1人あたりの粗利 | 6,000円 |
| 回収に必要な来店増 | **月9人** |
| 友だち1,000人での必要反応率 | **0.9%** |

友だち1,000人に配信して、月9人が来店すればペイする。反応率にすると0.9%です。この数字を自店の現場に置いてみて、届く数か届かない数か。そこが発注の判断基準になります。

気をつけたいのは、この計算を「初回来店1回分」でやらないこと。年4回通う常連が月に2〜3人増えれば、1年で見た粗利（1人あたり年間24,000円）で月額5万円分をまかなえます（回収は12か月かけての計算です）。LINEを受け皿にした集客の回収構造については、[友だち追加を入口にすると、集客コストの回収構造が変わる](/media/ad-line-funnel/)で詳しく書いています。

そして、この判断がいちばん効いてくるのは1年後・2年後です。広告は止めれば流入も止まります。一方、LINEの友だちリストは解約しても手元に残る。つまり月5万円は「配信作業の代金」ではなく、**顧客リストという資産を毎月積み上げるための投資**です。1年運用すれば、翌年は同じ広告費でも配信先が増えた状態からスタートできます。この視点があるかどうかで、同じ金額の見え方が変わります。

## よくある質問

### Q. LINE運用代行の費用は、最低いくらから頼めますか

配信代行のみに絞れば、月3万円前後から依頼できます。LAYRのサポートプランも月3万円（税抜）からです。ただしこの価格帯は「送る作業」の代行が中心で、戦略設計や改善提案までは入っていないケースがほとんど。安いのには理由があります。何を減らして安くしているのかを、必ず確認してください。

### Q. 初期構築費なしで、月額だけの業者を選んでも大丈夫ですか

条件次第です。すでにアカウントが構築済みで、配信だけ任せたいなら合理的な選択。一方、ゼロから立ち上げるのに初期0円なら、設計工程を省いているか、月額に上乗せして分割回収しているかのどちらかです。「初期0円」の中身が省略なのか分割なのか、そこを聞いてください。

### Q. 費用対効果が出るまで、どのくらいかかりますか

2〜3か月は見てください。友だちを集め、属性を取り、配信の反応を見て内容を調整する——この1周を回すのに、構造上それだけの時間がかかるからです。1か月で切らず、3か月分の数値の推移を見て継続を判断する。これが現実的な線です。

:::check{title="この記事のまとめ"}
- 費用は**初期構築費（10万〜50万円）／月額運用費（月3万〜30万円）／成果報酬**の3形態に分けて比べる
- 総額を決めるのは月額運用費。年間で見ると初期構築費より重い
- 代行費用の外側に、LINE公式アカウントのプラン料金とツール利用料が毎月かかる
- 価格差の正体は「任せる範囲」。安い＝悪ではなく、範囲が狭いだけのことも多い
- 判断は月額を粗利で割る。**月5万円÷粗利6,000円＝月9人の来店増**で回収できるか
:::

料金表を並べても、範囲が違うものは比較できません。まずは自社のLINEアカウントが今どの状態にあるか——設計に何が足りず、いくらかける価値があるのか。そこを掴んでから、複数社を比べてください。現状の把握には[無料のLINEスコア診断](https://check.layr.co.jp/)が使えます。設問に答えるだけで、アカウントの弱点と優先的に着手すべき項目が出ます。そのうえで具体的な見積もりが必要になったら、[お問い合わせ](/contact/)からご相談ください。他社と比較したうえで選んでいただいて構いません。

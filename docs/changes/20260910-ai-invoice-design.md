# AIサービスLP刷新の設計

- 対象: `/service/ai/`、サービス一覧のAI紹介。
- モード: A。読み物として、経営者が業務削減の価値と導入費用を判断できる構成。
- 確認済み正本: `src/styles/style.css` のトークン、`src/data/theme.json`、`docs/design-system/`、既存AIページ。
- 色: paper=白、black=見出しと価格面、text=本文、line=区切り、green-ink=強調、green-pale=補助面。既存変数を使用、グラデ・影・絵文字なし。
- 書体: 見出し・数字=Noto Sans JP 700、本文=同400、ラベル=同500。書体を追加しない。
- 型スケール: display=clamp(30px,3.6vw,48px)、h2=clamp(26px,3.2vw,38px)、h3=22px、lead=20px、body=16px、sm=14px、label=12px。価格のみdisplayの相対拡大。
- 余白: tight=6px、group=22px、block=56px、section=88〜168px / 56〜104px。モバイルは既存gutterを使用。
- レイアウト: 利益改善の見出しと請求書管理の構成例を左右に配置。直下に限定オファー。課題→自動化範囲→導入手順→自社実装例→FAQ→相談へ。
- signature: 大きな利益改善コピーに、受領→AI読取→確認という請求書管理の業務画面を組み合わせ、15万円→5万円の導入提案につなぐ。
- 余白の谷: 「毎月の作業を減らすことが、これからの利益につながる。」の締め行。
- 変更しないもの: ロゴ・連絡先・他サービスの価格・ブログ・管理画面・法務・共通トークン・トップFV。フッター装飾削除は別コミット。
- 今回はユーザーがコピー・デザイン全面刷新と価格変更を明示承認。既存の和風意匠・AI顧問を主役とした料金表・旧FAQを新提案に置換。
- オファー: 毎月5社、通常自動化費用15万円→5万円。既存AIページと同じ税別表記。月額ではなく導入費用。追加範囲・外部ツール費・保守は契約前に確認とし、未指定の条件を確定させない。
- 自動化の説明は受領請求書の整理・抽出・台帳転記を例示。画像は画面構成例と明示し、実績・削減保証にはしない。
- 自己審査: 抽象的なAI相談のページから、具体的な請求書業務と明示された初回導入費用で判断できるページへ変更。

- 最終検収で補助色をLP内のみ黒65%へ調整し、本文コントラスト4.5:1以上を確保。

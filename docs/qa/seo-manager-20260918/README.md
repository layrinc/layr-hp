## 制約と公開

管理ツールの編集はブラウザ内保存。クラウド同期、Google認証、Search Console API、自動順位取得は未接続。編集内容をLPやGitHubへ送る機能ではない。移行・端末変更・URL変更時はJSONバックアップを復元する。管理画面のnoindexはアクセス制限ではないが、配信データに業務メモ・取り込み済み実績は含めない。

プレビューとCIの最新URL・コミットはPR #31を参照。閲覧ツールでCloudflareプレビューが拒否されるため、実配信側の画面・ヘッダー・リダイレクトは未確認。本番はAGENTS.mdで定められた承認・マージ後。

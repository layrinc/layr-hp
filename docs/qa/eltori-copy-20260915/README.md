# エルトリ 名称・訴求・料金表示の更新（2026-09-15）

## 依頼と変更

- サービス名を「Lトリ」から「エルトリ」へ変更。LP、サービス一覧、共通フッター、お問い合わせの選択肢・件名、タイトル・構造化データを統一。
- Aboutを「広告費を、掛け捨てで終わらせない。LINEで、採用を『資産』に。」に変更。掲載後にも続く接点、登録済み候補者への再アプローチ、自社の採用リストの蓄積を説明。
- 指定の「配信してからがスタート。反応を見ながら、育てていく。」の特徴ブロックを削除し、特徴を3項目に変更。
- 月額5万円（税別）のスタンダードプランにオレンジの枠と「おすすめ」バッジを追加。

## 確認

- `npm run check`：50ページ生成成功、デザインゲートの悪化なし。
- Cloudflareの作業ブランチプレビューで1280 / 768 / 390のレイアウトを目視確認。横方向のはみ出しなし。
- 特徴3件、Aboutの訴求3件を確認。旧名称と削除対象の見出し・本文がLPからなくなっていることを確認。
- おすすめはスタンダードのみ。価格は月額5万円（税別）、枠の計算色は `rgb(255, 105, 0)`。
- スマートフォンのメニュー開閉と、プランCTAからお問い合わせへの遷移を確認。「エルトリ（採用LINE）について」の自動選択と「スタンダードプランについて相談したいです。」の引き継ぎを確認。フォームの送信は行っていない。
- スマートフォンで読みやすくなるよう、About見出しと「再アプローチ」の改行位置を調整。

プレビュー用のnoindexページ内に、指定幅の同一オリジンiframeを表示して確認。画像右側の灰色は確認用キャンバス。確認ページは本番へ含めない。

## デザインの例外と既存負債

端末の44px/35px等の物理的な丸みは「iPhoneに近い形」という明示指定に従う。一般カードへは適用しない。既存の端末影は既存トークン--sd-lgへ置換し、新色・新書体は追加しない。

全レガシーCSSへの単独ゲートでは既存の影・サイズ等も検出されるため、既存基準との回帰比較を採用。ltori.css単独で未定義と出る--black / --sd-lg / --r-pill / --radiusはstyle.cssの既存定義を使用。全体の未定義トークンゲートは0。

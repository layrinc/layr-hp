# メディア管理の自動取得表示 — design plan

- 対象: 認証管理画面 `/media/` のアクセス実績と取得状態。
- モード: D / utilitarian。既存 `style.css`、`seo-manager.css`、`media-manager.css` のトークン・書体・余白を確認し継承。
- 色: paper / bg / text / muted / line / green-ink。新しい色、影、書体、数値スケールは追加しない。
- 書体とサイズ: 既存 Noto Sans JP 400/500/700、kw-label/body/lead/h2 を使用。
- レイアウト: 上部サマリーを「Google接続」から「自動取得」へ変更。アクセス画面は自動取得状態・GA4/GSC各ソース・保存先・次回実行を先頭へ、手動期間指定と個別OAuthは折り畳む。
- signature: サーバーの最終成功・次回実行・部分失敗を見ながら、同じ表で実績を読める状態表示。
- 保存: サーバー最新snapshotはメモリ上で読込み、IndexedDBにある200企画・編集・CSV・手動履歴を変更しない。取得元を選択肢で明示。
- 同期完了: POST 202を完了扱いしない。GETでjobの終了またはソース取得試行の更新を確認する。重複実行を防ぎ、期限内に終了を確認できなければ「終了未確認」と表示。
- 今回変えないもの: 公開サイト、認証、バックエンドの取得仕様、既存手動履歴、記事企画、サービス価格・法人情報。
- 目視担当: rootが1280/768/390の実画面確認を行う。サーバー設定状況と実Google取得の可否はモックの検証結果と分けて報告する。

# 全国市LP・都道府県別公開の表示計画

- 対象: `src/pages/tools/ltori-seo/growth.astro` と `src/lib/seo-manager/growth-app.mjs` の公開状況表示。
- モード: D（社内ツール）。仕立て: utilitarian（機能優先）。
- 目的: 北海道から沖縄県へ、1日1都道府県・47日・792市の公開予定と、実際の公開・準備状況を区別して確認する。
- トークン正本: `src/styles/style.css`、`src/styles/seo-manager.css`、`src/styles/seo-growth.css` を実装前に確認。既存の書体、色、間隔、罫線、フォーカスを継承し、新しいCSSは追加しない。
- 既存と基準の差: system fontへの切替は行わず、既存のNoto Sans JPを維持。共通スタイルの既存負債は今回の変更対象外。

## 表現

- 紙面: `--paper` / 背景: `--bg` / 本文: `--text` / 補助: `--muted` / 罫線: `--line` / アクセント: `--green-ink`。値の追加なし。
- 見出し・本文・数字: 既存の `--font-jp`。太さ400 / 500 / 700。
- 文字: `--kw-h1`、`--kw-h2`、`--kw-lead`、`--kw-body`、`--kw-label`。実装は既存classのみ。
- 余白: tight 6px、既存行12px、group 22px、既存パネル32pxを継承。新しい値なし。

signature: 今日の都道府県と、47日程を俯瞰する折りたたみ表を一続きにする。

余白の谷は公開状況パネルと既存の成果・改善の間に置く。47行の表は初期状態で折りたたみ、既存のスクロール可能な表コンテナに収める。表に見出しscope・説明・キーボードフォーカスを付ける。

## 数値と状態

- APIの件数のみ表示。未取得・不正な件数は「—」、実測0は「0」。
- `day.status=completed` は「47日の日程終了」。残りの市があれば未公開数を併記し、全件公開済みとは表記しない。
- `ready` は未公開のうち承認済みの市、`missing` は未公開のうち準備が終わっていない市として説明。
- 一時停止、地域設定無効、開始前、進行中、日程終了を区別する。
- 市原稿の承認確認は都道府県予定日に従う旨へ変更。採用ノートの月10本・原則3日間隔は維持。
- 自動調査・制作の稼働設定、準備済み・要確認・処理中の件数を短い行で表示。未取得は「未確認」。要確認の市名は折りたたみで表示し、内部のエラーコードは表示しない。

## 変更しないもの

既存の成果指標、商談、原稿編集項目、Google接続、Access認証、公式メディアの運転設定、CSS・共通トークン・公開側サイト。

## 自己審査と検証

一般的な件数ダッシュボードではなく、都道府県単位の予定日と市単位の進捗を同時に示す。実行成功、予定日の終了、全市公開完了を混同しない。VMのDOMテストで状態と欠測を確認し、機械ゲートを実施。1280 / 768 / 390pxの目視確認はroot担当。

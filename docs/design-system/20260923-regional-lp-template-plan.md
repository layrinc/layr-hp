# 全国市LPテンプレート公開の設計計画

- 対象: 既存エルトリLPの地域別表示、全国SEO管理画面の制作方式表示。
- 指示: 公開済みの三重県等のLPをベースに、北海道→沖縄の1日1都道府県・全市を自動公開。AI APIは使わない。採用ノート月10本は次段階、公式メディアは保留。
- モード: 公開LPはA、別サイトの管理画面はD。いずれも既存デザインを継承。
- 仕立て: LPはeditorial、管理画面はutilitarian。
- 確認済みトークン正本: src/styles/ltori.css、ltori-area.css、style.css、seo-manager.css、seo-growth.css。
- 色: 公開側は既存の --lt-white / --lt-ink / --lt-green-ink / --lt-mint / --lt-gray。管理側は --paper / --text / --muted / --line / --green-ink。新しい値なし。
- 書体: 既存Noto Sans JP。見出し・本文・数字も既存クラスを継承。
- 型スケール: LPの既存hero/h2/h3/p/small、管理側の --kw-h1 / --kw-h2 / --kw-lead / --kw-body / --kw-label。追加CSSなし。
- レイアウト: 完成済みLPのhero→サービス説明→地域導入案内→業種別案内→料金・導入フロー→地域FAQ→相談導線を利用。
- signature: 完成済みのアイソメトリックイラストとオレンジCTAを維持し、地域に対応する見出し・案内だけをデータから適用する。
- 変更しないもの: 色・影・余白・書体・価格・サービス仕様・素材・既存の手作業原稿・メディア本文・認証方式。
- 自己審査: 新しい長文記事の自動執筆とは分け、地域マスターと確認済み共通LPを使う。市内の事業所・導入実績・雇用統計を創作しない。データ取得日を生成日で上書きしない。
- 管理画面: 「既存LPの地域展開」「有料AIは使用しません」と設定に応じて表示。準備と公開の実績を区別。開始日・終了予定・当日の県と件数を既存表で確認できる。
- 検収: 通常回帰ゲート、テンプレート全792市・出典・料金・改変検知のテスト、公開/予約境界、停止・競合・再実行、1280/768/390の見た目と横はみ出しを確認。

# エルトリ採用ノート：メディア構成の改修

## 2026-09-21 追加指定の実装計画

- モードA / editorialを継続。正式名は「エルトリ採用ノート」の維持を本人確認済み。
- 記事末尾は提示スクリーンショットに合わせ、編集部紹介 → 記事テーマに応じたエルトリ案内 → コンパクトなおすすめ → 画像付き関連記事とする。過去の販促枠なし指定は、この箇所について今回の明示指定を優先。
- 既存の公開記事は3本のため、自記事を除いた実在2記事だけ表示する。架空の記事・所要時間・監修実績は足さない。
- 画像は本人指定のISOME LAB素材へ統一。サイト公式の色変更機能で既存緑 #00BF63 に変更してSVG保存。クレジット不要を利用規約で確認し、出典は内部の素材台帳だけに記録する。サービス本体の画像は変更しない。
- ロゴは正式名称を読める文字主体にし、イラストを添える場合も同サイト素材だけを使う。生成イラスト追加の旧案は撤回する。
- Aboutページ・サイドバー・フッターからメディア専用お問い合わせページへ案内。受信先はsettings.jsonの info@layr.co.jp。既存FormSubmitを使用し、受付成功・失敗・重複・タイムアウトを処理する。個人情報は計測へ渡さない。実送信・受信確認は別途。
- 年間企画は2026年10月〜2027年9月、毎月10本。既存3記事の改稿・地域ページは新規120本に含めない。検索数は未計測、優先度は編集上の判断とする。
- 共通トークン、記事本文、会社情報、サービス料金は維持。ローカルビルド、フォーム模擬テスト、3幅の見た目、デザインゲートで検収する。

## design plan

- 対象: `src/pages/service/ltori/media/`、専用レイアウト・カード・サイドバー・CSS。Baseはフッター用の名前付きslotだけ追加。
- メディア名: **エルトリ採用ノート**。河出さんが2026-09-21に選定。サービス名「エルトリ」と区別する。
- モード: A。仕立て: editorial。既存の色と書体を使用し、構成は河出さん指定のKUZENブログに合わせる。
- 正本: `src/styles/style.css` の先頭・末尾定義、`src/data/theme.json`、既存 `ltori-media.css` を確認済み。共通トークンは変更しない。
- 色: 紙=`--paper`、本文=`--text`、補助=`--muted`、罫線=`--line`、アクセント=`--green-ink`。薄い面は既存の緑・黄・グレー系トークン。追加の色・グラデなし。
- 書体: 見出し・本文・英数字すべて `--font-jp`。400/500/700。
- 型スケール: display=clamp(30px,4vw,40px)、h2=clamp(24px,3vw,30px)、h3=20px、lead=18px、body=16px、sm=14px、label=12px。メディア内だけで変数化。
- 余白: 6px/22px/56px/88pxが基本。メインとサイドバー間38pxは指定参考の構成を優先。記事一覧はPC2列、1024px以下では1列、768px以下ではサイドバーも下へ。
- 角丸: 既存 `--radius` / `--r-lg` / `--r-pill`。影なし。hoverは色・罫線のみ。

## レイアウト

```text
メディア名       採用導線 / 応募後フォロー / 外注・比較 / 記事一覧 / About
ページ見出しと短い紹介           採用のアイソメトリック
サムネイル付き記事カード2列      最初に読みたい記事
公開日・カテゴリリンク           カテゴリー一覧
記事数に応じて「もっと見る」      メディア紹介
メディア専用フッター: About / 運営会社 / プライバシー / サービスサイト
```

- signature: サービスサイトの採用アイソメトリックと、カテゴリー別の淡い色面。記事カード2列＋右側の案内枠を継続。
- サムネイルはカテゴリーのラベルと既存の自社イラストを組み合わせる。個別のサムネイルがない新しい記事でもカテゴリーに応じて表示できる。記事タイトルはカード本文に全文表示する。
- KUZENの人気ランキング枠は、閲覧実績未取得のため「最初に読みたい記事」に置き換える。順番は編集上の読み方であり、人気順ではない。
- 見出しはイラストと並べて左揃え。記事一覧との間に56pxの余白を設ける。
- 今回変えないもの: 記事本文・既存URL、サービス名・料金、共通CSS、管理画面、フォーム受付、既存イベントと記事別source。他ページのフッターは維持。
- 自己審査: 公開3記事を正しく表示。薄い空ページの量産や架空の実績・人気順位は作らない。記事数が増えれば一覧・カテゴリー・件数は自動追随。

## 追加改修: サービスサイトの色・アイソメトリック表現

- 河出さんの追加指定: `https://layr.co.jp/service/ltori/` のUI/UX・色・アイソメトリックを参考に、メディアに彩りを加える。
- モードA / editorialを継続。実装前に共通CSSの全root定義・theme.json・サービス専用ltori.cssと本番画面を確認した。
- 色: 白=`--paper`、文字=`--text`、緑=`--green-ink`、薄緑=`--green-pale2`、補助面=`--iso-gray-2`、淡黄=`--mark-y-bg`。色の直値や共通トークンは追加しない。黄の使用は今回指定されたサービスサイトの意匠を優先。
- 書体・7段の型スケール・余白・角丸は既存メディアから継承。影・グラデ・追加アニメーションは用いない。
- signature: エルトリで使用している人物・スマホ・面接のアイソメトリックと、カテゴリーごとの淡い色面を組み合わせた編集面。
- 上部は短い紹介と採用全体のイラスト。記事一覧2列＋サイドバーを維持し、カテゴリーとAboutのページ見出しも同じイラスト付き構成に揃える。見出しブロックと記事一覧の間は56px。
- 記事サムネイルは単色に全文を重ねる形式から、カテゴリー名＋カテゴリー別イラストへ変更。記事の正式タイトルは直下に全文表示する。カテゴリーは色だけで識別しない。
- 既存の `public/service/ltori/isometric-*.webp` を再利用し、新しい画像ファイルを増やさない。画像には実寸と表示枠を指定し、カード画像は遅延読み込みする。イラストは装飾のため空alt。
- 今回変えないもの: メディア名、記事本文・タイトル・URL、3カテゴリー、運営情報、フォーム、イベント、サービスサイト本体、共通CSS。
- 自己審査: 汎用の図形で飾らず、ユーザー指定の自社サービス資産と採用の場面を対応させる。販促CTAや料金案内は増やさない。

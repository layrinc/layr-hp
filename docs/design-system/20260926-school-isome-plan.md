# オンラインスクールLP：アイソメラボ画像復帰・オレンジ強調

## design plan

- 対象：/service/school/ の画像と強調色。既存レイアウトの限定改修。
- モード：Aを土台とする既存参考LP準拠（河出さんの明示例外を維持）。仕立て：editorial。
- 正本：src/styles/online-school.css の実効トークンとレスポンシブ定義を確認。
- 最新指示：素材を除去せず、アイソメラボ画像をしっかり使用。削除対象は最下部の素材紹介URLのみ。下線と重要語はオレンジ。
- image2-design：生成は不要。既存の出典確認済みアイソメラボSVGを再利用し、別のAI画像には置き換えない。

### 色・書体・尺度

- 地：既存white/gray/green-soft。本文：black、補助：muted、罫：lineを維持。
- 主役：既存LINEグリーン。アクセント：orange（#ed7d16）、文字用orange-ink（#b84d00）。
- オレンジ用途：既存下線、受講申込の見出し、支援後の成果値。通常本文・相談CTAは緑/黒を維持。
- 書体：全役Noto Sans JP、既存ウエイト・48/40/24/20/16/14/12の役割を維持。追加サイズなし。
- 余白：既存tight/group/block/sectionを維持。画像表示領域のみ調整。

### レイアウト・signature

FV：コピー＋3つの訴求｜大きなチャットのイラスト＋既存5ラベル
対応範囲：イラスト＋見出し＋説明（3＋2）
専門チーム：各担当に異なるイラスト（3）
理由：成果イラスト＋本文

signature：緑の販売導線をアイソメラボの立体イラストで親しみやすく示し、申込・成果の重要箇所だけオレンジで際立たせる。
余白の谷：既存のスクール分野・CTA帯を維持。
重複：同じイラストは1ページ内で再使用しない。10種類を各1回。

### 変更しないもの

構成順、コピー、料金、実績値、パートナー注記、フォーム安全化、LINE相談CTA2か所、丸いトップ復帰、全サイト共通CSS、Worker設定。
フッターは運営会社・プライバシーポリシーのみ。素材紹介リンクは戻さない。

### 自己審査・出典

単なるピクトグラム置換ではなく、複雑な立体イラストが読める表示面積を確保。
公式利用規約 https://isome-lab.com/terms とFAQ https://isome-lab.com/faq を2026-09-26に確認。クレジットなしの企業サイト利用可。素材は既存ローカル配信を再利用し、直リンクしない。
内部の出典記録は保持し、画面には素材紹介URLを置かない。

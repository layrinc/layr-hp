# LINE支援カード：スマホ横スワイプ

- 対象: トップ「LAYRができること」とLINEサービスページの共通カード。
- モード: A（既存の緑白）。既存の画像・フォント・色・角丸を維持。
- トークン正本: src/styles/style.css / src/data/theme.json。新規トークンを作らない。
- 仕立て: editorial。PCは3列、タブレットは2列を維持。
- signature: スマホで次の制作例が少し見える、1枚ずつの横スワイプ。
- レイアウト: 600px以下だけ1行の横スクロールへ変更。カード幅90%、次のカードの一部を見せる。CSS Scroll Snapで止まる位置を揃える。
- 操作: ブラウザ標準のスクロール。自動再生・無限ループ・新規JSなし。スワイプ案内、キーボードフォーカス、スクロールバーを用意する。ページの縦スクロールは妨げない。
- 追加依頼: カードは「数値分析レポート」などの項目名だけを表示し、その下の大きな便益コピーを非表示にする。「詳しく見る」と開いた先の説明は維持。「掲載画像を拡大する」リンクを削除する。空いた余白に合わせ、カードの最小高を466pxから380pxへ調整する。
- 変えないもの: 画像6点、サービス名、詳細開閉、削除済みキャプション、FAQ、共通テーマ、他のセクション。データ内の便益コピーは保持するが表示には使用しない。
- 検証: 320 / 375 / 390 / 600 / 601 / 768 / 1280 / 1440px、末尾まで横移動、詳細開閉、キーボード、JSなしの構造、ページ全体の横はみ出し0、buildと回帰テスト・デザインゲート。

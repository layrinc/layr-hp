# 公式メディアの左側メニュー — design plan

- 対象: SEOワークスペース `/articles/`。採用ノートの操作方法に合わせて、上部の横並びタブを左側の常設メニューへ変更。
- モード: D / utilitarian。
- トークン正本: `src/styles/style.css`、`seo-manager.css`、`seo-workspace.css` を確認済み。既存の採用ノートの `kw-shell` / `kw-sidebar` を基準にする。
- 色: 地 `--bg`、面 `--paper`、本文 `--text`、補助 `--muted`、罫線 `--line`、選択 `--green-ink` / `--green-pale` / `--green-line`。既存の役割を再利用し、新色・影・グラデーションは追加しない。
- 書体: `--font-jp`。見出し700、本文400、ナビ500。英数字も同じ書体。
- 型スケール: 既存の `--kw-number:32px`、`--kw-h1:24px`、`--kw-h2:20px`、`--kw-lead:16px`、`--kw-body:14px`、`--kw-label:12px`。7段目は追加せず既存の機能用6段を維持。
- 余白: tight 6px、group 12/22px、block 32px、section 40px。採用ノート側の既存値を優先。
- レイアウト: 共通の施策切り替えの下に、左216pxのメニューと右側の作業画面。狭い画面では採用ノートと同じ縦積み・2列メニューとし、記事表のみ領域内スクロール。

```text
LAYR SEO WORKSPACE / 共通の施策切り替え
公式メディア     | 公式メディアの記事制作・公開・改善
 概要           | 選択した画面の情報と操作
 キーワード     |
 確認・公開     |
 原稿           |
 計測           |
 設定           |
 公開記事の改善 |
```

- signature: 採用ノートから移っても迷わない、左の作業メニューと右の編集画面。
- 余白の谷: メニュー見出しと項目群、最後の公開サイトリンクの間に設ける。機能用画面なので販促用セクションは追加しない。
- 変更しないもの: 記事本文・保存データ・API・運転設定・公開手順・他施策の既存UI。既存のタブID・リンクのハッシュを維持。
- 自己審査: 参照された採用ノートの画面構造を使い、七つの機能を一つのタブ一覧として残す。選択状態、キーボード操作、スマートフォンの幅を確認する。
- 検収: 1440/1280/768/390/375px、各タブ切替、深いリンク、原稿編集、未保存入力の保持、読み込み・エラー表示、回帰ゲート。既存許可の範囲でPR・本番反映まで進める。

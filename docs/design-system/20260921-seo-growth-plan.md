# エルトリSEO運用拡張

目的：市別LPと採用記事の作成・確認・予約公開・計測・改善を、既存のメール認証付き管理画面につなぐ。

管理画面は既存seo-managerの配色・余白・文字階層を踏襲する。上部に「本日の公開数 / 10」と予約残数・停止状態を表示し、原稿、成果、改善、接続の各作業をタブで分ける。未接続の計測値はゼロにしない。機密情報をブラウザに保存させない。

公開側はエルトリLPの白・緑と既存コンポーネントを再利用し、市別コンテンツを挿入する。個別LPに全国一覧・他都市一覧を戻さない。診断は既存LPから自然に移動できる入口とし、回答後に具体的な提案と相談導線を表示する。架空作例は明記し、改善率や実績を作らない。

確認：1280 / 768 / 390pxの画面、キーボード操作、保存競合、公開前後のアクセス制御、日次上限・重複防止、出典と公開条件、フォームの失敗時に成果を増やさないこと。既存デザインゲートを悪化させない。

公開はユーザーが今回承認済み。GitHub PRと必須CIを経由し、Cloudflare既存Workerへ反映する。認証設定を弱めたり、未設定のGoogle接続を成功扱いにしたりしない。

# antipatterns.md — 禁止リスト

`layr-design` の計画時（STEP 3 の design plan を書く前）に読む。

**トンマナの正本は資料**: `株式会社LAYR/06_デザイン_CDO/成果物/20260816_LINE構築運用サービス資料_トンマナ正本.pdf`（全24ページ）。
色・グラデ・角丸・見出しの型は資料の実測値が正。サイトの `style.css` は正本ではない（B-0参照）。
運用ルールの出典は `株式会社LAYR/06_デザイン_CDO/成果物/20260818_LAYRデザインシステム_監査と設計案.md` §6。

## この文書の読み方

- **A節** = AIが統計的に出してくる既定値。名指しで潰す。新規制作で発生させない。
- **B節** = LAYR資産で実際に起きたバラつき。**実測値は「既存資産の現状」であって「基準」ではない。**
  既存サイトの一斉是正（設計案 論点8）は未承認。既存を直しに行くのではなく、**新規に同じ形を再生産しない**ために読む。
- **C節** = 河出さんが過去に差し戻した指示。記憶ではなくここに固定する。
- **D節** = 資料（スライド・提案書）を作るときの禁止。Web専用ではない。

優先順位は **河出さんの明示指示 > 正本資料 > 対象プロジェクトの既存トークン > このスキルの基準**。
B節の実測値と衝突したら、そのプロジェクトの既存トークンに従い、逸脱をレビューで報告する。

## A. AI由来の統計的デフォルト

### A-1 タイポグラフィ

| 禁止 | なぜダメか |
|---|---|
| `Inter` / `Roboto` / `Arial` / `system-ui` / `Space Grotesk` を「選択」として使う | 選んでいない証拠。書体を検討した痕跡がゼロに見える |
| 英数字だけ欧文書体に切り替える | 資料は英数字（LIGHT / STANDARD / PDCA / 01）も和文書体で組んでいる。混植すると資料と別物になる |
| モードDの `system font` を A/B/C に流用する | Dのsystem fontは「道具だから速度優先」という意図的選択。名乗るものに使うと手抜きになる |
| `font-weight: 800` / `900` | Noto Sans JP は 400/500/700 しか読まない。合成太字で日本語が黒い塊になる。資料の見た目は900相当だが、Webはサイズと余白で強さを出す |
| 見出しを太さだけで立てる | 階層はサイズ・余白・色で作る。太さは最後の手段（原則2） |
| 字間を要素ごとにその場で決める | 種類が増えるほど「毎回決めている」状態になる。`letter-spacing` は4種以内 |
| 明朝を32px未満の本文・ラベルに使う | Bモードの明朝は大サイズ限定。小サイズで潰れて可読性が落ちる |

### A-2 色

**方針**: 主役は **ブランドグリーン #00BF63** の1色。ティール #0499AF → ライトグリーン #77D55C の横グラデは
**LAYRの正規の意匠**であり禁止対象ではない。禁止するのは「LAYR指定以外のグラデ」と「役割外の色使い」。

| 禁止 | なぜダメか |
|---|---|
| LAYR指定以外のグラデ（紫→青／サンセット／円錐レインボー／浮遊グラデオーブ） | 現代テック意匠で最も擦られた記号。何の会社かを一切語らない |
| LAYRグラデを本文背景や広い面にベタ敷きする | 資料でのグラデは **枠線・ピル帯・円バッジ・矢印** のみ。面に敷くと文字が読めず安く見える |
| グラデの向き・色順を変える（右→左、緑→青にする等） | 常に左端 #0499AF、右端 #77D55C。反転すると別ブランドに見える |
| 主役をグリーン以外にする | #00BF63 が主役。ティールは「グラデの片端」であって単独の主役ではない |
| サブ色を役割外で使う | 役割は固定。黄 #F6CC01＝倍率・強調バッジ、オレンジ #E9A32F＝推奨リボン、赤 #FF5757＝最大級の数値とステップ番号の丸、黄 #F2C650＝表紙の下線帯 |
| 面色を新しく足す | 面は 白／淡水色 #D6EEF1／淡緑 #DFF6EB・#E7F8F0 の3系統だけ。4系統目を作らない |
| アクセントの派生変数を新規に増やす | 変数があると使ってしまう。派生は `color-mix` / `oklch` をその場で書く |
| 本文を黒 #000000 で組む | 本文は #333333、見出しが #000000。両方黒にすると階層が消える |
| ダークモード風の紺黒ベタを社内ツールに使う | Dモードは白地＋1px罫。ダーク化は既に差し戻し済み（B-4参照） |

### A-3 レイアウト

| 禁止 | なぜダメか |
|---|---|
| 角丸をその場で決める | Webのカード・ボタンは **8px**。資料由来の板面（料金カード／番号付きカード／ラベル帯）を再現する時だけ **12〜16px**。16px超は使わない |
| 「ヒーロー→3カラム機能グリッド→推薦文→CTA」の型 | 最小抵抗経路。単カラム叙述／比較表／全面デモ／積層ケースを先に検討する |
| 等分3カラムの連打 | 「全部中央・全部等分」が最大の平凡シグナル。1ページに1回は崩す（原則6） |
| 全要素を中央揃え | 中央揃えは H1・締め行・最終CTA だけ。それ以外は視線の起点が消える |
| セクションの上下paddingを同値にする | 余白を設計していない最短シグナル。1.6:1 の非対称にする（原則5） |
| カードを影で浮かせる | 面の分離は1px罫かグラデ枠線。近くて濃い影は安く見える（原則4） |
| 2px以上のborderを一般の面に使う | 例外は資料由来の意匠のみ＝円形フローとカードのグラデ枠（`border:4〜6px solid transparent` ＋二重背景。資料上は10px相当）と見出し左の縦罫3px・Qバッジの白リング3px |
| 見出しの連番を装飾として置く | 連番は目次と一致する構造。飛ばさず、順番通りに、同じ大きさで置く（D-2参照） |

### A-4 モーション

| 禁止 | なぜダメか |
|---|---|
| 全要素一律のフェードイン | 「モーションがない」のと同じ。60msスタッガーに置換する |
| `transition` の easing 未指定（＝ブラウザ既定の `ease`） | 動きの性格を決めていない。全指定が高級側の共通点 |
| hover の向きをモードとずらす（Aで浮かせる等） | Aは浮かない／Bは沈む／Cは浮く／Dは背景色微変化。混ざると別サイトに見える |
| グラデをアニメーションさせる（回転・流れる背景） | 資料のグラデは静止した意匠。動かすとAI由来の装飾に戻る |
| `prefers-reduced-motion` を書かない | a11yの穴。演出は必ずオフにできる形で入れる |

### A-5 図版・素材

| 禁止 | なぜダメか |
|---|---|
| ダミー統計・意味のないチャート | data slop。画面上の数字は全て意味を持つこと |
| 偽の顔写真・偽のロゴ・架空の導入企業 | 信用に直接効く。実在しないものを出さない |
| 素材がない箇所をCSSシルエットやSVGで代用 | 「作った風」になる。`[hero: 実UIスクショ 1400×900]` のラベル付きプレースホルダを出す |
| **絵文字を見出しアイコンに使う** | 情報量ゼロの装飾。LAYRで実際に発生（B-4参照）。**資料も見出しには絵文字を使っていない** |
| 1行1アイコンの箇条書き | 大抵ノイズ。アイコンは意味を担うときだけ置く |

> 注記: 正本資料 p.17「ステップ配信制作」には絵文字が出てくるが、あれは **LINEメッセージの実例スクリーンショット相当の文面** であり、
> スライドのデザイン要素ではない。実際のLINE配信文を再現する箇所以外に絵文字を持ち出さない。

### A-6 コピー・構成

| 禁止 | なぜダメか |
|---|---|
| 「Build the future of ○○」「オールインワン・プラットフォーム」型 | 全サイトの平均値。何も言っていない。具体で書く |
| 頼まれていないセクション（私たちの価値観／選ばれる理由／チーム紹介）を足す | 埋め草。空いて見えるなら構成・スケール・余白で解く |
| 美的形容詞（premium / elegant / モダンで洗練された）で指示を出す | 判定できない。数値と手順で書く。再現プロンプトに入れると汎用マーケLPが返る |

## B. LAYR資産で実際に起きたバラつき（既存資産の現状）

実測は 2026-08-18 時点。対象は `株式会社LAYR/layr-hp/` 配下。

### B-0 サイトが正本資料とズレている（最上位）

| 禁止 | 実例（既存資産の現状） | なぜダメか |
|---|---|---|
| **サイトの `style.css` をトンマナの正本として読む** | サイトのブランド色はティール #0F9E96 単色。正本資料はグリーン #00BF63＋ティール→ライトグリーンのグラデ | 営業資料とサイトで別会社に見える。**新規制作は資料側に合わせる** |
| サイトの実測値から新しいトークンを起こす | 旧スキルは style.css から起こしたためグラデ禁止・アクセント1色という誤った基準になった | 由来がサイトだと、資料とのズレをそのまま増幅する。トークンの出どころは資料 |

### B-1 CSS運用

| 禁止 | 実例（既存資産の現状） | なぜダメか |
|---|---|---|
| CSSを末尾追記で積層する | `src/styles/style.css` が v7→v26。`.hero2-title` の `font-size` が4回、`.sec-en` が3回、`--muted` が2回定義 | 冒頭の `:root` だけ読むと実効値を誤る。**修正は既存定義を書き換える。末尾に「vNN追加レイヤー」を積まない** |

| 禁止 | 実例（既存資産の現状） | なぜダメか |

## B-x 一括置換でトークン化するときの事故（2026-08-19 実際に踏んだ）

CSSの直値をトークンへ寄せる作業は、次の3点を守らないと**壊れたことに気づけないまま本番へ出る**。

| 事故 | 何が起きたか | 防ぎ方 |
|---|---|---|
| **:root の定義行まで置換して循環参照** | `#D8E3E5` → `var(--iso-gray-3)` を全文置換した結果、定義そのものが `--iso-gray-3:var(--iso-gray-3);` になり、その色が全ページで無効化された。実際に `--paper` `--red` `--iso-gray-3/4` `--iso-ink-2` の5本が死んだ | 置換対象から **`:root` ブロックを必ず除外**する。定義行と使用箇所を同じ正規表現で触らない |
| **トークン定義の追加がスキップされる** | `if "--track-tight" not in s:` で追加要否を判定したが、先に使用箇所を `var(--track-tight)` へ置換していたため文字列が既に存在し、条件がFalseに。**定義なしで参照だけが残った** | 追加判定は `--track-tight:`（コロン付き＝定義の形）で行う。あるいは定義の追加を置換より**先**に実行する |
| **ロゴなど不可侵の値を丸める** | 字間を4スロットへ丸める際、`.brand-name` の `.32em`（ロゴの字間）まで対象に入りかけた | ブランド要素（ロゴの字間・社名の表記）は**専用トークンとして別枠**にし、丸めの対象から外す |

**手順の掟**: ① `--apply` を付けない dry-run を必ず先に実行して差分を目で見る ② 適用後は `grep -nE '\-\-[a-z0-9-]+:\s*var\(--' ` で循環参照が無いか確認 ③ **参照しているのに定義が無い変数**が無いか確認 ④ ビルドが通っても安心せず、必ずスクリーンショットで目視する（CSS変数の未定義はビルドエラーにならない）。

## C. 過去に差し戻された指示

**「◯◯風にして」で変えてよいのは、色・装飾・紋様・カード造形・影・枠・余白・モチーフ・レイアウトだけ。**

出典: よろず屋LP 江戸風リデザインでの差し戻し実例。

| # | 無断で変えないもの | なぜダメか |
|---|---|---|
| C-1 | 書体（筆文字・明朝・デコラティブへの置換） | 読み手は地方の社長。可読性が最優先 |
| C-2 | 文言・言い回し（世界観に寄せたリライト） | コピーは検証済みの資産。見た目の指示で書き換える対象ではない |

## D. 資料（スライド・提案書）を作るときのアンチパターン

正本資料の型を崩す作り方。Webではなく資料の話。

| # | 禁止 | なぜダメか（資料での実際） |
|---|---|---|
| D-1 | 1ページに詰め込む | 正本は1ページ1論点。p.2は「数字」だけ、p.10-11は「フロー」だけ。詰めた瞬間に商談で読み上げできなくなる |
| D-2 | 連番を飛ばす／振り直す | 01〜11が通し。子ページは親番号を保つ（07が①②で複数ページ）。飛ばすと目次と口頭説明がずれる |
| D-3 | 締め行「>> ○○」を全ページに入れる | 正本では章の切れ目だけ。毎ページ入れると強調が効かず陳腐化する。1章に1本 |
| D-4 | グラデを本文や広い面に敷く | 資料のグラデは 円フローの枠線・ラベル帯・番号バッジ・矢印 のみ。面に敷くと文字が沈む |
| D-5 | 写真を使わずCSS図形・アイコンで代用する | 事例ページ（p.11-12）は実写真。図形で代用すると事例の実在感が消える |
| D-6 | 数値をグラフだけで見せる | 正本は「グラフ＋円バッジの数値」の二段構え。9,600万人＝赤、約20倍/約6倍＝黄。読み手は数値だけ見て判断する |
| D-7 | 料金表で序列を見せない | 推奨はオレンジ #E9A32F のリボン、比較表の列ヘッダーはグレー→ブルー→オレンジで序列を作る。全列同色は選ばせる気がない表 |
| D-8 | ラベル帯ページに連番を振る | 「全体導線作成」「ステップ配信制作」等の内訳ページは連番なしのラベル帯で始まる。番号を振ると章立てが二重になる |
| D-9 | 表紙の波形・下線帯を毎ページ使う | 波形（淡緑 #C1E392→#B6DD75）と黄下線 #F2C650 は表紙・裏表紙だけの意匠。中面に持ち込むと締まりが消える |
| D-10 | 本文を黒 #000000 で組む | 本文 #333333、見出し #000000、非強調 #A6A6A6。3階調を守らないと全部が同じ強さになる |

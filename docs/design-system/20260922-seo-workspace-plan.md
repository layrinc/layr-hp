# SEOワークスペース統合 — design plan

- 対象: seo.layr.co.jp の全体概要、全国SEO、エルトリ採用ノート、LAYR公式メディア、共通戦略。
- モード: D 社内ツール / utilitarian。既存管理画面のスタイルを継承。
- トークン正本: src/styles/style.css の冒頭および末尾の実効値、src/styles/seo-manager.css を確認済み。既存Noto Sans JPと管理画面の型スケールを使う。
- 色: --paper（パネル）、--bg（地）、--text（本文）、--muted（補助）、--line（罫線）、--green-ink（リンク・選択）。新しい色・全体トークンは追加しない。
- 書体: 見出し700 / 本文400 / ラベル500。英数字も同書体。
- 型スケール: display=--kw-number 32px / h2=--kw-h1 24px / h3=--kw-h2 20px / lead=--kw-lead 16px / body=--kw-body 14px / sm・label=--kw-label 12px。
- 余白: tight 6px / group 22px / block 32px / section 40px。既存管理UIの余白を優先。角丸は既存--radius、影は追加しない。
- レイアウト: 共通の施策切替ナビと作業領域。概要は上段に実績、次に3施策の比較、下段に改善候補と接続状況。狭い画面は縦積みし、表だけ内側でスクロールする。

```text
LAYR SEO WORKSPACE                         認証 / ログアウト
全体概要 | 全国SEO | 採用ノート | 公式メディア | SEO・AIO戦略
概要タイトル / 最終取得 / 更新
検索クリック / PV / 問い合わせ / 公開ページ
施策ごとの範囲・実績・記事管理への入口
改善候補                              同期状況
```

- signature: URL範囲と実績の取得期間を同じ施策行に置き、3施策の重複計測を避けながら次の作業へ移動できる一覧。
- 余白の谷: 全体の指標と施策別の一覧の間。機能画面のため装飾的な締めセクションは設けない。
- 変更しないもの: 一般公開ページの意匠・本文、法人情報・価格、Googleの書込権限、認証許可リスト、既存保存データ、既存公開スケジュール、秘密情報。
- 自己審査: データのない施策は0にせず未取得と表示。メディア企画の端末保存とサーバー計測を区別。一般的なリンク集ではなく、同じ実績定義で3施策の運用を見渡せる概要にする。
- 検収: 1280/768/390pxと1440/375px、認証・alias、nullと0、URL範囲、取得元不一致、期間差、既存保存、計測先追加を検証。

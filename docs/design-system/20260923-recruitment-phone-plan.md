# 地域LPのスマートフォン作例 改修計画

- 対象: エルトリ共通LPの「候補者には、こんな体験を。」にある4シーンのトーク画面。地域一覧 `/service/ltori/area/` は廃止しサービスLPへ301転送。
- モード: A。既存エルトリLPのトークンと、利用者のiPhoneに近い立体的なモックアップ指定を優先。
- 仕立て: editorial。既存の左説明・右端末の構成を維持。
- 確認したトークン正本: `src/styles/ltori.css` の `.ltori`、`src/styles/style.css` の `:root` と再定義、`src/data/theme.json`。既存の独立エルトリ配色・オレンジCTAを継承する。

## 色・書体

- 紙・受信吹き出し: `--lt-white`。端末: `--black` / `--lt-ink`。金属縁と細線: 既存の黒白をcolor-mix。
- トーク背景: `--lt-gray` / `--lt-mint`。送信吹き出し・リッチメニュー: `--lt-green` / `--lt-green-ink`。既存色以外のhexを足さない。
- 見出し・本文・数字: 既存Noto Sans JP、400 / 500 / 700。
- 型スケール: 外側見出し・本文は既存のまま。端末内は本文13px、ラベル・時刻12px。12px未満にしない。
- 端末の物理的な丸み・黒いベゼルは端末造形として扱い、一般のカードへ展開しない。既存端末のハード影を既存 `--sd-lg` の柔らかい影へ置換。サイト全体の影の種類を増やさない。
- 余白: 外側セクション余白を維持。端末内部の小さな余白は6px、12pxを基準に既存値から整理する。

## レイアウト

黒いベゼルと細い金属縁を持つ縦長の端末に、カメラ部、時刻・通信・電池、会話ヘッダー、左右の吹き出し、リッチメニュー、入力バー、ホームインジケーターを配置。外側の説明とタブ機能はそのまま使い、細い画面でも端末と文字を潰さない。

```
既存の4シーンタブ
説明文・相談導線       金属縁 / 黒ベゼル
                      9:41   カメラ   通信・電池
                      みどり製作所｜採用
                      ○ [受信メッセージ]
                           [候補者の返信]
                      [リッチメニュー]
                      [入力バー / ホームバー]
                      架空の企業の作例です
```

- signature: 採用候補者の手元で開くLINEのトークを想像できる、実機に近い端末と会話の作例。
- 余白の谷: 既存のシーン説明と端末の間、セクション前後の余白を維持。
- コピー: 既存の企業名・受信文・選択肢は維持。候補者の短い返信だけを作例として足す。実企業の画面・公式認証バッジ・ブランドロゴは使用しない。
- 動作: 4つのシーン切替を維持。画面内の装飾は押せる実機能のように見せてフォームへ誤送信させない。必要な箇所だけ縦スクロールでき、読み上げとキーボード操作を妨げない。

## 今回変えないもの

各市のURL・LP本文・料金・CTA・公開済み/予約データ・公開日程・採用ノート・公式メディア保留。地域一覧の廃止は完全一致URLだけに適用し、市LPと静的/動的サイトマップの発見経路を維持。

## 追加指示: 地域写真の全面見直し

写真下の名称・連番と写真帯の市名見出しを撤去。写真は地域名の一般カテゴリからの選出をやめ、地域内の異なる観光名所3〜4箇所を起点にする。原寸横1600px以上の鮮明な横位置写真を選び、同じ名所の連写や一般道路・市役所・車窓・標識を埋め草に使わない。市の取り違え・不明なライセンス・不足する枚数を無理に補わず、地域と利用条件を確認したセットを表示する。低品質な旧選定は再取得対象とする。必要な出典・作者・ライセンスは折りたたみの写真クレジット内に保持し、見た目のラベルとは切り離す。取得方式は無料の公開APIに限定し、LP訪問時に外部APIを呼ばない。

## 検収

4シーン、静的/動的LP、1280 / 768 / 390幅で確認。横はみ出し、文字切れ、タブの選択・フォーカス、作例明示、問い合わせ導線を確認する。地域一覧の3URL形は301、市LPは200、未公開市は404、一覧はサイトマップに含まれないことを検証する。

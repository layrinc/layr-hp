# 記事制作機能の統合 — design plan

- 対象: SEOワークスペース `/articles/`。記事つくる君のキーワード管理・生成・承認・原稿編集・計測・運用設定を同じ作業画面に統合。
- モード: D / utilitarian。既存のSeoWorkspaceレイアウトを継承。
- トークン正本: `src/styles/seo-manager.css`、`src/styles/seo-workspace.css` と基になる `src/styles/style.css` を確認済み。
- 色: --bg（地）、--paper（面）、--text（本文）、--muted（補助）、--line（罫線）、--green-ink（選択）。新しい色・グラデーション・影は追加しない。
- 書体: 既存 --font-jp。見出し700、本文400、ラベル500。
- 型スケール: --kw-h1 24px、--kw-h2 20px、--kw-lead 16px、--kw-body 14px、--kw-label 12px、数値 --kw-number 32px。
- レイアウト: 共通の施策ナビの下に、制作状況／キーワード／確認・公開／原稿／制作側の計測／設定／公開記事の改善を切り替える作業ナビを置く。表は領域内で横スクロールし、狭い画面は縦積み。

```text
LAYR SEO WORKSPACE / 共通ナビ
公式メディアの記事制作・公開・改善
制作状況 | キーワード | 確認・公開 | 原稿 | 計測 | 設定 | 公開記事の改善
対象画面の情報と操作
```

- signature: 記事の制作状況から公開後の改善まで、同じメニューで辿れる運用画面。
- 変更しないもの: 公開記事の本文、価格・法人情報、既存の自動運転モード・公開上限・定期処理、既存D1のデータ、生成キー。今回の確認で記事を新規生成・公開しない。
- 自己審査: 既存ツールへのリンク追加だけで終わらせず、制作機能をこの画面で操作できるようにする。市場検索数、サジェスト代理値、GSC実績を混同しない。未接続は0と表示しない。
- 検収: 1280/768/390px、キーボード、原稿編集・エラー時の入力保持、認証・CSRF・内部APIの制限、保存先維持、二重生成・二重公開の防止を確認。

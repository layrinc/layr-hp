# エルトリ採用ノート管理 — design plan

- 対象: `/tools/ltori-seo/media/` を生成し、認証ホスト `https://seo.layr.co.jp/media/` で提供。
- モード: D / utilitarian。既存地域SEO管理のUIを継承。
- 正本: `src/styles/style.css` の実効トークン、`src/styles/seo-manager.css` の管理画面用サイズ・コンポーネントを確認済み。
- 色: paper / bg / text / muted / line / green-ink。新規色は追加しない。実測0だけblack/paperの反転で表現し、必ず「確認済み0」を併記。
- 書体: 既存Noto Sans JP 400/500/700。英数字も統一。
- 型スケール: `--kw-label` 12 / `--kw-body` 14 / `--kw-lead` 16 / `--kw-h2` 20 / `--kw-h1` 24 / `--kw-number` 32 を再利用。
- レイアウト: 左ナビ＋作業領域。上部に企画数・取得状況、下にフィルターと表。スマホはナビを上段へ配置し、横に長い表だけを内部スクロールにする。
- signature: 検索需要の根拠と制作状況を同じ記事行で確認し、実測0・範囲値・未取得を混同しない一覧。
- 初期データ: 元120案のIDを保持し、潜在層候補と調査済みレポートを保護HTMLへ埋め込む。公開client bundleには含めない。
- 今回変更しないもの: 地域SEOのDB・計測ロジック、一般公開メディアのCSS、公開記事本文、法人情報、料金、認証メール許可リスト。
- 自己審査: 装飾ではなく需要→制作→公開後実績の順で判断できる設計。管理画面に販促CTAの意匠を持ち込まない。

## データの意味

検索数は取得元の月間検索数。ラッコの表示0は絶対に検索が存在しないことを証明しない。GSCの表示回数は市場検索数に転用しない。順位1位でも検索数と同数のPVを保証しない。取得条件をレポート単位で保持し、異なる条件を合算しない。

GA4はPV・ユーザー・流入セッション・CTAクリック・相談完了・資料請求完了を分離。GSCのページ別実績と検索クエリを分離。返らない指標は未取得表示のまま。Google取得は手動、読み取り専用。接続tokenはメモリ内だけ。

## 保存と公開の境界

編集と取得実績はこのブラウザのIndexedDBに保存。JSONバックアップで移行できる。端末間同期・定期無人取得・記事公開操作・Sheetへの書き戻しは行わない。静的初期企画だけをCloudflare Accessで保護して配信する。公開previewの管理HTMLは403。認証なしは失敗閉鎖。

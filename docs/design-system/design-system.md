## 2. トンマナ4モードの定義と選び方

判定軸は「社内/対外」ではなく「**LAYRとして名乗るか / 自分の道具か**」。

```
Q1. LAYRとして名乗るものか？
    NO  → モードD（社内ツール）
    YES → Q2へ
Q2. 河出さんから世界観の明示指示があるか？
    NO  → モードA（コーポレート・資料トンマナ）＝標準。迷ったら必ずA
    YES → 「AI感を消す／読み物として売る」 → モードB（エディトリアル）
           「屋号もの／和の商い」           → モードC（和風）
```

**モードA＝サービス概要資料のトンマナ**（2026-08-18 全面差し替え）。主役はブランドグリーン `#00BF63`、意匠はティール→ライトグリーンのグラデ `#0499AF → #77D55C`。旧A（ティール `#0F9E96` 単色・グラデ禁止）は破棄した。LP・サービスページ・提案書・サービス資料・ホワイトペーパーはすべてこのモードで作る。

- **標準はA。迷ったらA。** BとCは河出さんの明示指示がある時だけ発動する。レイが勝手に世界観を振らない。
- **B・C は A の派生ではなく別体系。** Aの緑・グラデをB/Cへ持ち込まない。逆にB/Cの明朝・ハード影・淡黄マーカーをAへ持ち込まない。
- **1プロジェクト＝1モード。** 混在させない。ページ内で切り替えない。
- **B・Cのトークンはページscoped変数で持つ**（`--edit-*` / `--wa-*`）。グローバル `:root` を上書きしない。
- **DはAの色を使うかどうかだけ判定する。** 名乗るものならブランドグリーン `#00BF63` を1色だけ、自分の道具なら無彩色。**Dではグラデを使わない**（意匠は対外物のもの）。ツール固有の業務色を新規に作らない（既存ツールの固有色は維持）。
- 販促ポップ調（LINE緑 `#06C755` ×オレンジCTA×絵文字アイコン）は正規モードにしない。新規では使わない。ブランドグリーン `#00BF63` と LINE緑 `#06C755` は別物。混同しない。

## 3. モード共通のハード制約8条

全モードで守る。数えて判定できる形だけを条文にした。

1. **値の種類を減らす。** 1プロジェクト内で font-size の数値リテラル ≤10 / letter-spacing ≤4 / border-radius ≤5 / box-shadow ≤8。型スケールを `:root` に7段だけ宣言し、素のpxを書かない。角丸は 8 / 12 / 16 / 999px の4値で足りる（資料実測）。
2. **階層は太さで作らない。** 使用ウエイトは 400 / 500 / 700 の3値のみ。**800・900 の出現数 = 0**（Noto Sans JP は実グリフを持たず合成太字になる。資料は900相当に見えるが、Webではサイズと余白で強さを出す）。英数字も和文と同じ書体で組む。
3. **色は「役割」で持つ。主役はグリーン `#00BF63` の1色。** サブ色は用途が決まっているものだけを、その用途でだけ使う — 黄 `#F6CC01`（数値の強調バッジ）／オレンジ `#E9A32F`（推奨リボン）／赤 `#FF5757`（最重要数値の円・ステップ番号）／淡水色 `#D6EEF1`（面・タグチップ）／淡緑 `#DFF6EB`・`#E7F8F0`（薄い面）。**役割外で使わない。色相をこれ以上増やさない。** 1ビューポート内で主役の塗りは最大3箇所。派生が要る時は変数を増やさず `color-mix` / `oklch` をその場で書く。見出しの強調は1語だけ（文全体を色にしない）。
4. **グラデーションは LAYR指定の1本だけが正規。** ティール `#0499AF` → ライトグリーン `#77D55C` の横方向グラデ。用途は資料に出てくる4つに限る — ラベル帯（章の小見出しピル）の塗り／円形フローの環／番号バッジの円塗り／フロー間の三角矢印。表紙・裏表紙の有機的な波形だけは淡緑 `#C1E392 → #B6DD75` を使う。**AI由来のグラデ（紫→青、浮遊グラデオーブ、虹色、放射状の光）は全面禁止。** 本文・カード地・ボタン塗りにグラデをかけない。
5. **面の分離は1px罫かグラデ枠線。影で浮かせない。** カードは `background:#fff` + 罫線。単色の `border-width` は 1px のみ。**意匠としてのグラデ枠線（円形フローの環・番号付きカードの枠）は太さを持ってよい**が、`border:Npx solid transparent` ＋ `padding-box`/`border-box` の二重背景で持つ（`border-image` は角丸と併用できない）。単色borderを太らせない。影を許すのはモーダル／ドロップダウン／固定ヘッダーの3用途だけ。hoverは `border-color` を1段濃くする。
6. **余白は非対称。** セクションの上下padding比 ≒ 1.6:1。近接は4段に固定し中間値を作らない（tight 6px / group 22px / block 56–96px / section 88–168px）。
7. **中央揃えは H1 / 最終CTA / セクション締め行 の3用途だけ。** `text-align:center` ≤5。等分3カラムの連打を1ページに1回は崩す（崩しは1ページ2〜3箇所まで）。
8. **1ページに「記憶に残る1つ」を作り、それ以外は黙らせる。** design plan に `signature:` を1行で書けないなら着手しない。あわせて「1文しか置かないセクション」を1つ作る（`padding-block: clamp(128px,15vw,240px)`）。資料でいう「>> ◯◯◯」の締め行がこれに当たる。

## 5. アクセシビリティ最低線

- 本文のコントラスト **4.5:1 以上**。大見出し（24px以上、または18.66px以上の太字）は **3:1 以上**。
- `:focus-visible` を必ず定義する。フォーカスリングを消さない。
- タップ領域は **44×44px 以上**。
- `prefers-reduced-motion: reduce` に対応する。
- `<h1>` は1ページにちょうど1つ。装飾テキストを見出しタグで代用しない。
- **1440 / 768 / 375** の3幅で横スクロールを出さない。
- 色だけで情報を伝えない（状態はテキストか形も併記）。

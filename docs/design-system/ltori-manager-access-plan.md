## 実装・切替の条件

- 既存Worker `layr-hp` に専用ホスト `seo.layr.co.jp` を追加する想定。新規Workerは作らない。
- 全リクエストをWorkerに通し、管理パスの直接アクセス・HTML別名もJWT検証する。専用ホストでは公開LPを配信しない。
- Cloudflareの実設定はセキュリティ検証で未確認。DNSを推測で変更しない。
- 許可メールアドレス、AccessアプリのAUD、チームドメインを確定してから本番切替する。設定不足時は管理画面を閉じる。
- 既存ブラウザの作業データはJSONで移行。ログインによる複数端末の自動同期は追加しない。

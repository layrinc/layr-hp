# 公開ペースと保留状態 — design plan

- 対象: SEOワークスペースの公開・運用、地域管理、公式メディアの運転設定。
- モード: D / utilitarian。
- トークン正本: `src/styles/seo-manager.css` と既存の `20260923-corporate-sidebar-plan.md` を確認。地 `--bg`、面 `--paper`、文字 `--text` / `--muted`、罫線 `--line`、選択 `--green-ink` を再利用。
- 書体: 既存 `--font-jp`、見出し700・本文400・ラベル500。数字も共通。
- 型スケール: 既存32/24/20/16/14/12pxを維持。新規CSS・色・サイズは追加しない。
- レイアウト: 公開状態の既存領域に「全国SEO 今日 / 20地域」と「採用ノート 今月 / 10本」を並べる。公式メディアは全タブ共通の保留表示と、設定画面の専用再開ボタンを設ける。
- signature: 公開枠と原稿の準備数を区別し、3施策の運転状態を読み違えない。
- 変更しないもの: 記事本文、保存済み原稿、既存計測値、配色、ナビゲーション構造。
- 自己審査: 月間枠を日次枠として見せない。未取得を0表示しない。通常の設定保存で保留を解除しない。
- 検収: 公開枠分離と停止の機能試験、ビルド、デザイン回帰ゲート、1280/768/390pxの表示確認。

# オンラインスクールLINEサービスLP 公開確認

## 目的・承認

河出さんの明示指定 https://layr.co.jp/service/school へ独立したサービスLPを追加する。
既存のLAYRテンプレートではなく、確認済み参考LPの構成・表現を維持するという指示を優先。
第三者の画像素材は使わず、10種類の独自SVGを各1回配置。

## 範囲

- /service/school/、専用CSS/JS、サービス料金データ、10 SVG。
- 丸いトップ復帰ボタン（PC72px、モバイル60px）。
- ヘッダー問い合わせ右、下部問い合わせ直前のLINE CTA。
- 問い合わせはメール下書き。自動送信せず、未送信であることを明示。
- JS不調時は下書きボタンを無効化し、PIIの標準GET送信を防止。
- 料金は確定回答の25万円〜／月5〜10万円／月20〜30万円。税区分を推測せず、正式な総額は見積もりで案内。

- Cloudflare dry-run成功。既存Worker/D1/service bindingを変更せず維持。
- 公開前プレビュー: https://1e06ef2f-layr-hp.biz-oneservice.workers.dev/service/school/

- 1280/768/390の確認画像は screenshots/school-*.jpg。

## 意匠ゲートの扱い

専用CSSはユーザー指定の参考デザインを維持する明示例外。
通常LAYR意匠ゲートは7/12項目で基準外（影・中央揃え・サイズ等）。
共有スタイルやゲート基準値は変更せず、既存サイトの回帰はなし。
これは通常ゲート全項目PASSという意味ではない。

## 公開方式

作業ブランチ→PR→Cloudflareプレビュー→CI合格→承認済み公開依頼に基づきマージ→検証済みバージョンを本番へ昇格。
DNS・独自ドメイン・既存の非バージョン設定を変更しない。

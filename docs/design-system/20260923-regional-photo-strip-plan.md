# 地域LPの写真スライド design plan

- 対象: 地域LPのHero直後、現在の黄色い英文帯。
- モード: A。既存エルトリLPの緑・黄色・オレンジCTAを継承。
- 仕立て: editorial。実写の地域風景を3〜4枚、一列に並べる。
- 指示: 各市に関連するネット上の画像を自動取得し、広めの横スライドで地域感を出す。
- トークン正本: src/styles/ltori.css / ltori-area.css / style.css を確認済み。既存の角丸・色・書体を優先する。
- 色: 地 --lt-white、見出し --lt-ink、補助 --lt-gray、罫線は --lt-ink の混色、アクセント --lt-green-ink、ラベル --lt-yellow。新しい色・グラデ・影は足さない。
- 書体: 既存Noto Sans JP。見出し700、本文400、写真名500、英数字も同じ。
- スケール: display/h2/h3/leadは既存クラス。新規写真名14px、操作・出典12px（既存サイズ）。
- 余白: tight 6px、group 22px。帯内は上下22px、既存Hero/Aboutのセクション余白を保持。
- レイアウト: 市名と『この街の風景』、停止/再開・左右操作、小さな写真クレジット。PCは約360px幅×220pxの写真を横一列、スマートフォンは次の写真が少し見える幅で横スワイプ。画像は寸法指定・lazy loading。
- signature: 採用サービスのアイソメトリックHeroから、その市の実際の街並み・自然へつながる横長の写真帯。
- 余白の谷: 写真帯とAboutの間に既存の白い余白を維持。
- 動作: 停止可能な自動送り。手動操作・フォーカス中は停止。prefers-reduced-motionでは自動送りしない。キーボードとタッチに対応し、ページ全体の横はみ出しを出さない。
- 情報: 地域一致と利用条件を検証できる写真だけを使用。出典・作者・ライセンスを写真クレジットに表示。他市の写真で不足を埋めない。写真未準備でも全国LPの公開スケジュールを止めない。
- 今回変えないもの: LP本文・価格・問い合わせ先・サービス素材・公開日程・採用ノート・公式メディア保留。
- 検収: 静的名張/動的札幌で共通描画、3サイズ目視、操作/停止/動き軽減、外部URLと文字列の検証、既存公開/予約処理への回帰なし。

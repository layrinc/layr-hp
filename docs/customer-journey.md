# 広告・LP・LINE・成約をつなぐ顧客導線

## 対象と構成

対象は公式サイトのトップ `/` のみ。`/service/line/` は改修前の内容を維持する。トップのヒーロー文言・CTAは `page-home.json` を使用し、料金・事例・フォーム・資料請求・シミュレーターのデータと機能は変えない。

ファーストビューの円形導線は、広告で出会い、LPで興味を深め、LINEでファンになり、納得して成約する流れを示す。ユーザーの最新指示により、直後の「HAPPINESS GOES AROUND」セクションは文章・画像・リンクを含めて削除した。導線のスキップリンクは次のサービスセクションを指す。PHILOSOPHYは3つの輪が重なる図案に置き換え、見出し・説明文・カードを表示しない。

素材は立体感のあるSVGイラスト。WebGLによる3Dモデルではない。追加の依存ライブラリなし。

## スクロール

`progress = clamp((headerHeight - sectionTop) / (sectionHeight - viewportHeight))` の0〜1の値から、円の線・現在地・表示する文章・LINEシナリオの表示を決定する。自動再生、経過時間、慣性補間は使わない。スクロールと画面サイズ変更時だけ再描画する。

工程リンクから直接移動でき、「サービスを見る」で長いスクロールをスキップできる。JavaScript無効時と、文字拡大・低い画面で内容が収まらない場合は縦並びですべての説明を表示する。動きを減らす設定ではリンク移動を即時にし、シナリオのフェードを省く。

画像の外枠と画像本体に左右の自動マージンを設定し、残す図版は各カード・カラムの中央にそろえる。PHILOSOPHYは画面幅に合わせて全体を縮小する一枚のSVGとして表示する。その他の文章の左揃えは維持する。

共有Blockの `isometric` オプションはトップだけで有効にし、サービス詳細ページには適用しない。

## 三方よしの3つの輪（2026-09-12）

`PhilosophyRings.astro` がトップのmvvブロックの位置に表示される。上にお客様、左下に企業、右下に社会を表す輪を配置し、互いの重なりで「三方よし」を表現する。英字見出し、日本語見出し、各カードの文章は表示しない。読み上げ向けのSVG title/descのみ残す。

スクロール中は、セクションの画面内位置から計算した0〜1の進行度を角度に変換し、光点が各輪を巡る。同じスクロール位置では同じ角度に戻り、停止時に自動で動き続けない。マウスを重ねると輪とアイコンがわずかに反応する。動きを減らす設定では回転・ホバー移動を止める。外部画像・追加ライブラリなし。既存色トークンのみを使用。

# 広告・LP・LINEで集客から販売までつなぐ顧客導線

## 対象と構成

対象は公式サイトのトップ `/` のみ。`/service/line/` は維持する。ヒーロー文言とCTAは `page-home.json` を使用する。料金・事例・フォーム・資料請求・シミュレーターのデータと機能は変更しない。

ファーストビューは、広告・LP・LINEの3つの円形図版を三角形に配置する。広告でお客様を集め、LP（商品紹介ページ）で商品の魅力を伝えてLINE登録へ案内し、LINEで信頼を築いて購入につなげる。成約は独立した工程にせず、購入後のフォローまでLINEの説明に含める。図版の下には「集客から販売まで一気通貫で支援します」を表示する。

ユーザーの明示指示により、PHILOSOPHY／三方よしのセクションは、3つの輪・文章・カードを含めて全体を削除した。「HAPPINESS GOES AROUND」も引き続き表示しない。導線のスキップリンクはサービスセクションを指す。

素材は立体感のあるSVGイラスト。WebGLによる3Dモデルではない。追加の依存ライブラリなし。

## スクロール

`progress = clamp((headerHeight - sectionTop) / (sectionHeight - viewportHeight))` の0〜1の値から、円の線・現在地・表示する文章・LINEシナリオの表示を決定する。自動再生、経過時間、慣性補間は使わない。スクロールと画面サイズ変更時だけ再描画する。

工程数は表示データから取得する。LINEの工程では現在地をLINEの円に留め、メッセージを順に表示する。工程リンクから直接移動でき、「サービスを見る」で長いスクロールをスキップできる。

JavaScript無効時と、文字拡大・低い画面で内容が収まらない場合は縦並びですべての説明を表示する。動きを減らす設定ではリンク移動を即時にし、シナリオのフェードを省く。

## 画像の配置

残す図版は各カード・カラムの中央にそろえる。本文の左揃えは維持する。

| --- | --- |
| FV | ISOME LABの広告・LP・チャットの3点 |
| サービス | 構築用のリッチメニュー端末、運用用の配信カレンダー。各1点 |
| できること | アカウントカード、シナリオ工程、制作ボード、広告ターゲット。各1点 |
| 特徴 | ISOME LABの協働イラスト。1点 |

| 料金・料金シミュレーター | アイコンなし |
| コラム・FAQ・会社概要 | 見出しのアイコンなし |
| PHILOSOPHY／三方よし | セクション全体を削除 |
| お問い合わせ | 返信カードと封筒。1点 |

同じバナー・クリエイティブを使い回さない指定に従い、下部の図案は内容ごとに作成したオリジナルSVG（`src/lib/home-isometric-scenes.mjs`）。使用する8図案をトップで1回だけ使用し、配布素材の加工・複製は行っていない。色は既存CSSトークンから取得し、アニメーションや外部読み込みはない。会社ロゴ、メンバー写真、コラム記事の画像、操作用の矢印は維持する。

共有Blockの `isometric` オプションはトップだけで有効にし、サービス詳細ページには適用しない。

## 素材と既存ルール

ユーザーによる「ISOME LABからマーケティングに近い素材を選んで使用」「円形のイメージを既存の公式サイトに入れる」という明示指示に基づき、AGENTS.mdの他社素材・FV画像禁止について下記の素材を限定して使用する。画像の中央配置と、今回のヒーロー見出し・説明文の平易化も明示指示を優先する。CTAと規則ファイル自体は変更しない。

配布元の公式色変更機能で緑色にしたSVGをローカル配信する。外部サイトへのホットリンクは使わない。著作権は原権利者に帰属。商用サイトへの組み込み・色変更は許可されており、素材単体の販売・再配布用途には使用しない。出典リンクを表示する。

```sh
npm run check
npm run check:cloudflare
```

公開は既存Cloudflare WorkersのGit連携を使用。作業ブランチとPRで確認し、承認に基づきマージする。今回の継続修正は会話内の「OK本番」の公開承認を引き継ぐ。

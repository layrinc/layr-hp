# 広告・LP・LINE・成約をつなぐ顧客導線

## 変更の目的

公式サイトのトップとLINE事業ページに、広告で出会い、LPで興味を深め、LINEでファンになり、納得して成約する流れを組み込む。最後はお客様・企業・LAYRの三方が成果を喜ぶ構成。

- 対象: `/` と `/service/line/`
- トップのヒーロー文言・CTAは `page-home.json` をそのまま使用。
- 共通のヘッダー・フッター、既存の料金・事例・フォーム・資料請求・シミュレーターを維持。
- Astroの共通コンポーネントで描画。追加の依存ライブラリなし。
- 素材は立体感のあるSVGイラスト。WebGLによる3Dモデルではない。

## スクロール

`progress = clamp((headerHeight - sectionTop) / (sectionHeight - viewportHeight))` の0〜1の値から、円の線・現在地・表示する文章・LINEシナリオの表示を決定する。自動再生、経過時間、慣性補間は使わない。スクロールと画面サイズ変更時だけ再描画する。

工程リンクから直接移動可能。「三方よしの、その先へ」で長いスクロールをスキップできる。JavaScript無効時と、文字拡大・低い画面で全内容が収まらない場合は縦並びですべての説明を表示する。動きを減らす設定ではリンク移動を即時にし、シナリオのフェードを省く。

## 素材と既存ルールの扱い

今回のユーザーによる「ISOME LABからマーケティングに近い素材を選んで使用」「承認した円形のイメージを既存の公式サイトに入れる」という明示指示に基づき、AGENTS.mdの他社素材・FV画像禁止について、この5点のSVGを対象に限定して使用する。規則ファイル自体は変更していない。素材はローカル配信し、外部サイトへのホットリンクを使わない。

配布元の公式色変更機能で緑色にしたSVGを使用。著作権は原権利者に帰属。商用の企業サイトへの組み込み・色変更は許可されている。素材単体の販売・再配布用途には使用しない。出典リンクを表示する。

```sh
npm run check
npm run check:cloudflare
```

公開は既存Cloudflare WorkersのGit連携を使用。作業ブランチとPRで確認し、承認・マージ前に本番を変更しない。

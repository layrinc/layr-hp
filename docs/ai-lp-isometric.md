# アッシュクAI LPのUI・UX刷新（2026-09-12）

## 対象
`/service/ai/`。ユーザー指定の `/yorozuya/` を構成・読みやすさの参考にする。よろずや自体、公式トップ、LINEサービスページは変更しない。

既存のサービス名・ヒーロー文言・3プランの料金と条件・支援実績は `src/data/service-ai.json` から取得する。料金データ・FAQの回答・構造化データは維持する。

## 構成
よろずやの大きな見出し、内容ごとのまとまり、比較しやすいカード、明確な相談導線を採用する。和風の意匠は移植せず、白・緑とアイソメトリック素材で社内の業務自動化を表現する。

1. 大きな冒頭コピーと、社内の仕事→AI・人の協働→コスト見直しの図解
2. 毎月の手作業・経費・本業に関する悩み
3. 作業整理、既存ツールとの連携、使い方までの支援という3つの特徴
4. 6つの業務分野を読みやすいカードで表示
5. AIに任せる作業と人が確認する作業の比較
6. 請求書自動化・月額コンサル・専用開発の3プラン
7. 請求書自動化の限定プランの詳細
8. 支援実績と、開閉して見られる自社ツール画面
9. 導入の流れ、FAQ、サービス全体の無料相談

終了時の相談先を請求書プランだけに限定せず、サービス全体の相談に変更する。実際にLINE・メールへ進むリンクで既存のgenerate_leadイベントを送る。ページ内リンクでは送信しない。

スマホではヘッダーをコンパクトにし、比較・料金・業務カードを縦に並べる。本文は14px以上、補足は12px以上。外部フォント・アニメーションライブラリは追加しない。FAQと実装例はネイティブdetails、相談は既存のLINE・メールを使う。

## デザイン
大きな中央の見出しと、白／淡い緑のセクションで読む順序をつくる。本文はカード内で左揃え、イラストは中央。金額と従来の課題など、強調が必要な箇所は既存の深い赤を使う。独自の色コードや共通スタイルの上書きは追加せず、既存トークンから派生させる。

ユーザーの明示指示により、AGENTS.mdの外部素材・FV画像禁止について今回のISOME LAB素材を限定して使用する。中央見出し、カード、余白、文字サイズの変更も今回のUI・UX刷新の範囲として行う。規則・基準値自体は変更しない。

CIのAstro build・デザインゲート・Cloudflare dry-runを実行し、既存Workerのプレビューで表示とリンク、FAQ、実装例の開閉を確認する。確認結果はPRに記録する。接続ブラウザーは固定幅のため、1280 / 768 / 390pxの指定サイズおよびスマートフォン実機の表示確認は未実施。

## 現行のシミュレーション（簡略化）
- ユーザーの追加指示により、入力は業務チェックリスト（6種類）・選んだ業務すべての月の合計作業時間・担当者の時給だけとする。
- 料金プラン・ツール費用・経費が減る割合・削減率スライダー・回収期間をシミュレーションから削除。料金カードは左から請求書・コンサル・開発のまま。
- 作業時間の50%をAIへ任せる仮の条件を明示し、確認・修正に使う時間を残す。業務の選択数で時間を掛け算しない。
- 結果は「毎月空く時間」「単純作業の工数換算＝空く時間×時給」「営業・顧客との対話・商品改善へ使う価値＝空く時間×3000円」。
- 後者の3000円/時間はユーザー指定の仮の換算単価。実際の増益・売上を保証せず、同じ時間の2つの評価額を利益として加算しない。導入・運用費用は含まないことを表示。
- 初期値は入力例（請求書・入力転記、月80時間、時給2500円）。空く時間40時間、工数換算10万円/月、活用価値12万円/月。
- 無選択・空欄・負数・上限超過を扱い、リセットで入力例へ戻す。JavaScriptが使えない場合は入力例を読み取り専用で表示。
- 入力値や選択内容の保存・外部送信・計測は追加しない。相談は既存の相談セクションへ移動する。
- 計算関数はsrc/lib/ai-cost-simulation.mjs、回帰テストはtests/ai-cost-simulation.test.mjs。ゼロ、小数、無効値、選択数が増えても合計時間を重複計上しないことを検証する。

# トップページのクライアントロゴ帯

`ClientMarquee.astro` をトップの顧客導線の直後、サービスの前に配置する。

## 現在の状態

2026-09-12時点で、既存サイトの実績データは匿名。参照画像はデザイン例として受領したもので、画像に写っている企業をLAYRの支援実績として掲載するかは未確定。`src/data/clients.json` は空配列としている。空の場合は、見出し・枠・余白を含めてセクションを出力しない。架空のクライアント名や代替ロゴは置かない。

掲載する企業名とロゴが確定したら、ロゴを `public/images/clients/` に保存し、`items` に実名の `name` とローカルの `logo` パスを登録する。画像は内容を変形させず同じ大きさの白いカード内に収める。

## 挙動

- PCではゆっくり横に流れ、停止・再開ボタンを表示する。ホバー・キーボードフォーカスでも停止する。
- タッチ画面と動きを減らす設定では自動移動を使わず、横スワイプで閲覧する。
- 読み上げ対象は元の企業リストのみ。ループ用の複製は読み上げない。
- 色と角丸は既存トークンを使用し、カードに影は付けない。
- 本番での企業ロゴ入り表示・動作確認は、掲載企業と素材を登録した段階で実施する。

同時にファーストビュー冒頭を「LINEマーケティングで、事業を加速させる。」へ戻す。広告・LP・LINEの説明とスクロールギミックは維持する。

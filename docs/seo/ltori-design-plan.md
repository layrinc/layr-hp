# エルトリ 地域LPのテンプレート方針

更新: 2026-09-17。最新のユーザー指定「既存サービスLPの構成・デザインをテンプレートとして使い回す」を正本とする。以前のコーポレート緑白の地域ガイド案を置き換える。

## 共通テンプレート

`/service/ltori/` の既存実装を `ServiceLanding.astro` に抽出。汎用LPも地域LPもこのコンポーネントを使用する。`ltori.css` の既存サービス専用デザイン、ヒーロー画像、採用LINEのイラスト、黄色のマーカー、オレンジの相談ボタンをそのまま利用する。

ヘッダー→ヒーロー→帯→サービス概要→採用ニーズ→特徴→相談バナー→4つの活用シーン→6つの提供内容→料金3プラン→導入5ステップ→FAQ→最終相談バナー、という既存構造を引き継ぐ。地域LPではFAQの後に地域リンクを追加する。

## 地域ごとに切り替える箇所

| 箇所 | 名張市の例 |
| --- | --- |
| title | 三重県名張市の採用LINE構築・運用支援｜エルトリ｜株式会社LAYR |
| H1 | 三重県名張市の採用LINE構築・運用支援 |
| ヒーローの前置き・説明文 | 三重県名張市の企業さまへ／オンラインでサポート |
| サービスH2 | 三重県名張市の採用活動に。採用LINEを、まるごと支援。 |
| FAQ | 三重県名張市の企業でも依頼できるか、オンラインでの進め方 |
| 相談バナー | 三重県名張市の採用担当者さまへ |
| パンくず・地域リンク | 全国一覧→三重県→名張市 |
| URL・canonical・Service構造化データ | /service/ltori/area/mie/nabari/ |

地域LPに追加するCSSは `ltori-area.css` のみ。既存 `--lt-*` トークンを使用し、新しい色・素材・影は追加しない。長い地域名は折り返し、スマートフォンの横はみ出しを検査する。

都道府県LPも同じサービスLPを表示し、その下部に県内の全地域リンクを置く。全国一覧は同じサービスのブランドヘッダー・書体・配色を用いた索引ページとする。

## 確認対象

1280 / 768 / 390pxの地域LP画面、長い地域名、都道府県LP、全国一覧、元のサービスLPを確認する。料金・CTA・資料リンク、シーン切り替え、モバイルメニュー、キーボード操作、問い合わせ元の引継ぎも検査する。`layr-design` / `layr-design-review` の確認手順を使用し、意匠の選択は最新のユーザー指示を優先する。

## 2026-09-18：地域コンテンツの追加

ユーザー提示のHリンク画面にある地域解説・業種リンク・町域一覧・地域別サービス紹介を追加。元LPの概要後に地域解説、サービス内容の後に業種と対応エリア、FAQの後に地域向けサービス紹介を配置する。元LPの既存セクションの前後関係は維持する。

色は既存 `--lt-ink` / `--lt-green-ink` / `--lt-white` / `--lt-mint` を使用。本文16px、補助文14px、既存見出しサイズを継承。新しい色・影・画像は追加しない。業種例は1pxの枠と既存角丸トークン、町域は読みやすい一覧とし、390pxでは1列にする。既存のフォーカス表示・モーション低減・フォーム計測を継承する。

地域情報は日本郵便の原典と照合。架空の地区、未確認の産業集積、架空の導入実績や競合の少なさを文章に混ぜない。文字だけのキーワード一覧にせず、業種リンク先に用途・配信案・メニュー例を置く。

# エルトリ 全国SEOキーワード管理

2026-09-18。地域LPを運用するための管理ツールを `/tools/ltori-seo/` に実装する。LPの「ほかの対応地域」と直下の都道府県・全国一覧リンクはユーザー指示により全地域から削除。パンくず、都道府県の子地域一覧、全国索引、サイトマップは維持する。

## Design plan

- 対象: 全国の地域ページ・対策キーワード・検索実績・改善タスクの管理。
- モード: D（LAYR社内ツール）、utilitarian。既存LPの意匠は維持する。
- トークン正本: `src/styles/style.css` の全4箇所の `:root` と `src/data/theme.json` を確認。既存トークンを優先し、独自の色・書体・角丸・影は増やさない。
- 色: 紙 `--paper`、地 `--bg`、文字 `--text`、補助 `--muted`、罫 `--line`、操作の強調 `--green-ink` / `--green-cta`。グラデーションなし。
- 書体: 見出し・本文・英数字とも `--font-jp`。400 / 500 / 700。数字はtabular-nums。
- 型スケール: label 12px、body/sm 14px、h3/lead 16px、h2 20px、h1 24px、集計32px。既存のサイズ集合から選択。
- 余白: tight 6px、group 22px、block 32px、画面の上下32/22px。機能画面にはLP用の大きなセクション余白を持ち込まない。
- レイアウト: 左に短い業務メニュー、右に集計・絞り込み・一覧。地域を選ぶと詳細編集ダイアログ。狭い画面ではメニューを折り返し、表内だけを横スクロールする。
- Signature: 「地域 → 狙うKW → 実績 → 次にやること」を同じ地域レコードでつなぐ台帳。未測定は数値ゼロと区別する。
- 余白の谷: ページ見出しと集計、その下の作業一覧を罫線と余白で分離。
- 変更しないもの: 既存LPの画像・価格・本文、既存CMS、会社情報、法務、記事、既存Workerの配信構成。
- 自己審査: ダミーの順位や折れ線グラフを置かない。1,965地域の正本からキーワード候補を生成し、取り込んだ検索実績と明確に区別する。

## 保存と実績

編集内容はこのURLを開いたブラウザのIndexedDBに保存する。外部サーバー・GitHubへ編集データを送らない。複数タブからの古い状態での上書きを検知する。端末やURLが変わる場合はJSONバックアップを復元する。自動クラウド同期・Google認証・Search Console APIによる自動取得は含めない。

Search Consoleのページ別・クエリ別CSVを取り込む。期間と検索条件を利用者が指定し、保存前に取り込み件数と対象外行を確認する。同じ期間・条件・集計軸は置換し、二重計上しない。異なる期間や集計軸の数値を合算しない。クエリ別実績は、ページ絞り込みが未指定ならサイト全体の実績として表示する。表示回数があってもインデックス状態を自動確定しない。

出典: [Google 検索パフォーマンスレポート](https://support.google.com/webmasters/answer/7576553?hl=ja)。平均掲載順位は検索時点・地域・端末等を含む集計値であり、固定の順位ではない。CSVの行数制限や匿名化等によって、CSVに現れないデータがある。

管理画面はnoindex、サイトマップ対象外。管理UIはアクセス制限ではない。配信されるデータは公開LPの地域・URL・キーワード候補だけで、業務メモと検索実績は利用者のブラウザ内に留まる。

## 日常の操作

1. 「地域・ページ」で地域を検索し、地域名を押す。次の作業・担当・期限を記入して保存する。
2. 「キーワード」で対策対象を確認する。各地域の編集画面で候補を保留にし、実際に狙う検索語を追加する。標準候補は実測した検索ボリュームを意味しない。
3. 「実績・入出力」でSearch ConsoleのCSVを指定し、期間・条件を合わせて内容確認→保存する。ページのフィルタをかけたクエリCSVでは、その対象ページも指定する。
4. 一覧の「表示する検索実績」で期間を切り替える。未取り込みやCSVにない数値は「—」で表示する。「改善タスク」で期限や対応状況を確認する。
5. 作業後はJSONバックアップを保存する。端末やプレビュー/本番URLを変える際は同じバックアップを復元する。CSV出力は他の表計算ソフトで確認するためのもので、復元にはJSONを使う。

保存上限は20MB、60実績、100,000実績行。上限到達時はバックアップを保存し、不要な検索実績を削除する。CSVの比較エクスポート、ページ×クエリの複合集計、UTF-8以外は受け付けず、理由を表示する。Google Search Consoleでのデータ表示・書き出しが必要で、このツールからGoogleへのログイン情報を入力する必要はない。

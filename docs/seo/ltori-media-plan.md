# エルトリメディア

公開先は /service/ltori/media/。一般LINEメディアとは記事・目的を分離し、採用担当者からエルトリへの相談獲得に限定する。既存地域LP・料金・管理画面は維持する。

signature: 採用の「集める・つながる・面接へ進む」を横並びの編集ナビとして示し、記事から次の行動へ案内する。

## 編集フロー

検索意図を確認 → 既存記事との重複を確認 → 公式資料と自社の確認済み情報を収集 → AI下書き → 人が事実・引用・比較基準・CTAを確認 → PR → 承認後公開。
新規記事は draft:true が初期値。未承認の大量公開、競合情報・成果数値の創作、地名だけの置換記事は行わない。
初期3記事は公開候補。今回のPR承認が公開レビューであり、まだ本番未反映。
比較記事には運営者を明記し、調査日・比較対象の選定基準・一次情報を付ける。自社への恣意的な順位付けはしない。

## 計測

記事のCTAクリックは ltori_media_cta_click。問い合わせ完了は既存フォームの generate_lead のみ。両者を混同しない。
Search Consoleのページ別表示・クリックと問い合わせの質を月単位で確認。順位や流入は未取得を0扱いしない。
AI自動生成API・GSC自動取得・CompanyBrain同期・定期公開は今回未実装。既存の地域SEO管理ツールに二重の保存先を増やさない。

## 地域・業種SEOの編集基準（ユーザー提供の投稿本文を反映）

参考X: https://x.com/akiharu_0309/status/2101234045770440883 。投稿への直接アクセスは不可。ユーザーが提供した①タイトル②H2③読者が知りたい内容の3点を以下の形で採用する。

### 検索する人を取り違えない

対象は採用担当者・企業経営者。例として「大阪市 建設業 採用LINE」「介護 採用 応募後 連絡」を検討する。「大阪市 建設 求人」など求職者向けの検索は主目的にしない。候補キーワードの検索需要は未調査であり、検索ボリューム・順位を創作しない。

### タイトルと見出し

- 地域LPは地域名＋採用LINEなどのサービスを自然に前方へ入れ、本文の内容と一致させる。既存の地域LPタイトルはこの型を実装済み。
- 地域と業種を掛け合わせる記事例：「大阪市の建設業で採用LINEを使うには？応募後の連絡と運用の確認点」。地域固有の調査ができるまでは公開しない。
- H2には見出しの内容に必要な場合だけ地域・業種を入れる。すべてのH2に同じキーワードを反復しない。
- 全国共通のノウハウ記事には無関係な地名を足さない。既存の地域LPと同じ検索意図の記事を増やさず、記事から適切なLPへ案内する。

### 読者の判断材料

採用担当者の疑問に応じて、対象企業、解決できる課題と限界、具体的な配信・予約の手順、初期費用・運用費・別料金、必要な社内作業、導入手順、対応地域・オンライン対応、相談先を記載する。
料金は src/data/service-ltori.json を正本として表示する。実績や地域特性は確認済みの情報だけを使い、地域に拠点があるような表現を創作しない。
地域記事では、関連する自治体・労働局等の一次資料を調べ、対象期間・地域・出典URL・確認日を残す。地名と業種名だけを置換した大量ページは作らない。

### AI検索への対応と表現

読者の質問への回答を見出しの直後に置き、重要な情報を通常のHTML本文として読めるようにする。内部リンクと構造化データを本文に一致させる。
「地域名をH2に入れれば必ず順位が上がる」「検索1位・AI推奨が保証される」は採用しない。GoogleのAI Overviews / AI Modeに特別な最適化要件はないとされており、表示や引用は保証されない。他のAIサービスについても同様の挙動とは断定しない。

公式確認資料:
- https://developers.google.com/search/docs/appearance/title-link （簡潔で内容を説明するタイトル、キーワード詰め込みの回避）
- https://developers.google.com/search/docs/appearance/ai-features （GoogleのAI検索機能への基本方針）

公開前には、検索意図／固有の根拠／自然なタイトル・見出し／費用と支援範囲／問い合わせ導線を確認する。今回の反映は編集基準であり、未調査の地域×業種記事を公開したものではない。

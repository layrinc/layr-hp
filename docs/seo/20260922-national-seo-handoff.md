# 全国市区町村SEO 開発チャットへの共有文

SEO管理ツールを、既存の `https://seo.layr.co.jp/` 内へ統合する方針に決まりました。全国市区町村SEOの開発も、以下の構成に合わせて引き継ぎ・連携をお願いします。

## 決定した構成

- `https://seo.layr.co.jp/`：SEOワークスペース全体概要。各施策の進捗・検索実績・PV・取得状況を横断して確認。
- `https://seo.layr.co.jp/regional/`：全国市区町村SEOの地域・キーワード・改善管理。
- `https://seo.layr.co.jp/media/`：エルトリ採用ノートのSEO管理。
- `https://seo.layr.co.jp/articles/`：LAYR公式メディアのSEO管理。
- 共通の公開・運用は `/growth/`、共通戦略は `/strategy/` に配置。

実際のサブドメインを3つ作る構成ではありません。同じSEOワークスペース内のページとして、共通メニューから切り替えます。公開サイトのURLは引き続き、全国SEOが `/service/ltori/area/`、採用ノートが `/service/ltori/media/`、公式メディアが `/media/` です。

## 引き継ぎ・実装上のお願い

1. 全国SEOの既存データ・地域マスター・キーワード・メモ・進捗・公開予約を保持し、初期化や別DBへの作り直しはしないでください。現行の地域保存先 `/api/seo/state` と既存D1を継続利用します。
2. 全国SEO画面の入口は `/regional/` に合わせてください。root `/` は全体概要になるため、地域管理へ戻るリンクと、概要へ戻るリンクを区別してください。
3. 各ページは一意のURLで集計し、採用ノートや公式メディアとの二重計上を避けてください。市・区・町・村の対応範囲は実装・公開状態に合わせ、未対応を公開済み扱いしないでください。
4. Google認証・GA4・Search Console・定期取得は共通基盤を利用します。新しい認証方式や別の定期取得ジョブを重ねて作らないでください。未取得の数値を0に変換しないでください。
5. 統合側で、共通ナビ、rootと各画面のルーティング、概要API、公式メディアの取得範囲追加を実装しています。全国SEO側で同じファイルを変更する場合は、先に変更箇所を共有してください。全国SEOの固有機能・地域情報の拡充を中心に進めてください。
6. 地域情報の根拠、読者の採用課題、具体的な対応策を確認して公開する方針です。地名だけを差し替えた記事量産は行いません。記事の新規作成・統合は、共通SEO／AIO戦略に合わせます。

# LAYR HP 管理画面（CMS）の使い方

WordPressの管理画面に相当する、記事の投稿・編集画面の使い方。

- **管理ホーム: https://layr.co.jp/admin/**（入口はここだけ覚えればOK。WordPressの管理画面ホーム相当）
  - 記事数・下書き・最終デプロイ日時
  - **やることリスト（自動判定）**: サンプル数値のまま／写真未設定／LINE URL未設定などを検出し、1クリックで該当の編集画面へ
  - 記事一覧（編集・表示への直リンク）、①〜⑬セクションへのクイック編集
- **カスタマイザー: https://layr.co.jp/admin/customize/**（WordPressのカスタマイザー相当・ライブプレビュー付き。**サイト設定はここで編集するのが基本**）
  - 左パネルで **色・角丸・フォント／全セクション（①〜⑬）の文言・数値／追加CSS** を編集 → 右の実サイトに**即時反映**
  - PC／タブレット／スマホの表示切替つき
  - 「保存して公開」→ GitHubに保存され約1分で本番反映（CMSログイン済みならトークン不要）
  - **追加CSS** = WordPressの「追加CSS」相当。自由なCSSがサイト全体に適用される
- 編集画面（CMS）: **https://layr.co.jp/admin/cms/**（**記事の執筆**と、項目の追加・削除・画像アップロードはこちら）
- 旧 /dashboard/ は /admin/ に自動転送される

## ログイン方法は3つ

管理画面を開くと、3つのボタンが出る。

### ① ローカルリポジトリで作業（設定ゼロ・今すぐ使える）
- パソコンのこのフォルダを直接編集する方式。GitHub連携不要。
- 手順: `npm run dev` でローカルサーバーを起動 →　http://localhost:4321/admin/ →「ローカルリポジトリで作業」→ ダイアログで `company-brain` フォルダを選択。
- Chrome または Edge で開くこと（この機能はChromium系ブラウザ専用）。
- 保存すると手元の `.md` ファイルが更新される。公開するにはデプロイが必要（下記）。

### ② アクセストークンでログイン（外出先からでも・5分設定）
- GitHubの「個人アクセストークン」を作って貼るだけ。OAuthサーバー構築は不要。
- 手順:
  1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** で新規作成
  2. リポジトリは `layrinc/company-brain` を選択、権限は **Contents: Read and write** を付与
  3. 生成されたトークンをコピー
  4. 本番の `/admin/` を開き「アクセストークンを使用してログイン」→ 貼り付け
- 以降はブラウザに記憶され、どこからでも投稿・編集できる。

### ③ GitHubにログイン（本格運用・要OAuth設定）
- ボタン一発でGitHubログインできる方式だが、OAuth中継サーバーの用意が必要。
- 外注ライターに配る等で必要になったら、レイに「GitHubログインを有効化して」と言えばセットアップ手順を案内する。

**おすすめ**: まず①で試す → 普段使いは②。

## 記事を書く流れ

1. 管理画面 → 左メニュー「コラム記事」→「新規作成」
2. フォームを埋める:
   - **タイトル**: 記事の見出し
   - **説明文**: 検索結果・一覧に出る説明（SEOに効く。100字前後）
   - **URLスラッグ**: 記事URLになる英語の短い名前（例: `line-step-message`）
   - **公開日**: 日付
   - **カテゴリ**: LINE運用 / LINEマーケティング / 広告運用 から選ぶ
   - **下書き**: チェック中は公開されない。完成したら外す
   - **本文**: マークダウンで書く（見出し・箇条書き・太字が使える）
3. 「保存」→ 記事が `src/content/blog/` に追加される
4. **公開**: 現状はデプロイが必要（下記）。トップのコラム欄・一覧・サイトマップには自動で並ぶ。

## 公開（デプロイ）について

**保存＝公開が有効になっている。** 管理画面で「保存」すると GitHub に記事がコミットされ、GitHub Actions が自動でVercelへデプロイ → **約1〜2分で本番サイトに反映**される。WordPressの「公開」と同じ感覚で使える。

- 反映状況は GitHub → Actions タブ（https://github.com/layrinc/company-brain/actions ）で確認できる。
- すぐ反映されない時は1〜2分待つ。それでも出なければレイに「layr-hpの反映確認して」と言う。

## ページビルダー（WordPressのブロックエディタ相当）

**https://layr.co.jp/admin/customize/** — トップページを「ブロックの積み重ね」として自由に組み替えられる。SWELL / JIN:R / AFFINGER系のWordPressテーマの編集体験を踏襲。

### ブロックは3カテゴリ

- **🔤 基本パーツ**: 見出し（2/3/4）/ テキスト / ボックス / セクション見出し（LPと同デザインの英字＋大見出し）/ 画像 / ボタン / 余白
- **✨ 装飾パーツ（WPテーマ風）**: キャプションボックス（色付きタイトルバー）/ アイコンボックス（💡ポイント・⚠️注意・📝メモ・✅チェック）/ 吹き出し（顔アイコン付き会話）/ リスト（✓チェック・①番号・›矢印）/ ステップ / アコーディオン / 引用 / 2カラム / 記事リスト（最新コラム自動）
- **📦 完成セクション**: ヒーロー・実績数値・CASEなどデザイン済みの大きな部品（テンプレート）

### 文字装飾（本文の中を部分的に装飾）

テキスト・ボックス・吹き出しなどの本文は、**文字をドラッグで選択**してツールバーから装飾できる:
**B 太字 / 緑マーカー / 黄マーカー / 緑文字 / 赤文字 / 🔗リンク / ⌫解除**

### 操作

- **文字サイズ**: どのブロックにも「文字サイズ（このブロック全体）」があり、小（90%）/ 標準 / 大（112%）/ 特大（125%）から選べる
- **追加**: 「＋ ブロックを追加」または各ブロックの＋（好きな位置に挿入）
- **並べ替え/複製/削除**: 各ブロックの ↑↓ ⧉ 🗑 — パズルのように組み替えられる
- **画像**: 画像ブロック・吹き出しアイコン・代表写真は「📁 画像を選ぶ」でアップロード（保存時に自動でサイトに格納）
- **デザイン・全体設定タブ**: テーマカラー・角丸・フォント・追加CSS・連絡先
- 右のプレビューに**即時反映**。「保存して公開」で約1分後に本番へ

ページの実体は `src/data/page-home.json`（ブロック配列）。レイに「◯◯ブロックを追加して」と言っても同じものが編集される。

## デザインを変えたいとき

文言・数値は上記「サイト設定」で。**レイアウト・色・余白などの見た目**はコードを触る。Claude Codeでレイに指示するのが早い（例:「ヘッダーの色を変えて」「サービス欄の見出しを大きく」）。デザインの正本は `src/styles/style.css`。

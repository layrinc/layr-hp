# LAYR HP 管理画面（CMS）の使い方

WordPressの管理画面に相当する、記事の投稿・編集画面の使い方。

管理画面URL: **https://layr-hp.vercel.app/admin/**

---

## ログイン方法は3つ

管理画面を開くと、3つのボタンが出る。

### ① ローカルリポジトリで作業（設定ゼロ・今すぐ使える）
- パソコンのこのフォルダを直接編集する方式。GitHub連携不要。
- 手順: `npm run dev` でローカルサーバーを起動 →　http://localhost:4321/admin/ →「ローカルリポジトリで作業」→ ダイアログで `company-brain` フォルダを選択。
- Chrome または Edge で開くこと（この機能はChromium系ブラウザ専用）。
- 保存すると手元の `.md` ファイルが更新される。公開するにはデプロイが必要（下記）。

### ② アクセストークンでログイン（外出先からでも・5分設定）
- GitHubの「個人アクセストークン」を作って貼るだけ。OAuthサーバー構築は不要。
- 手順:
  1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** で新規作成
  2. リポジトリは `layrinc/company-brain` を選択、権限は **Contents: Read and write** を付与
  3. 生成されたトークンをコピー
  4. 本番の `/admin/` を開き「アクセストークンを使用してログイン」→ 貼り付け
- 以降はブラウザに記憶され、どこからでも投稿・編集できる。

### ③ GitHubにログイン（本格運用・要OAuth設定）
- ボタン一発でGitHubログインできる方式だが、OAuth中継サーバーの用意が必要。
- 外注ライターに配る等で必要になったら、レイに「GitHubログインを有効化して」と言えばセットアップ手順を案内する。

**おすすめ**: まず①で試す → 普段使いは②。

## 記事を書く流れ

1. 管理画面 → 左メニュー「コラム記事」→「新規作成」
2. フォームを埋める:
   - **タイトル**: 記事の見出し
   - **説明文**: 検索結果・一覧に出る説明（SEOに効く。100字前後）
   - **URLスラッグ**: 記事URLになる英語の短い名前（例: `line-step-message`）
   - **公開日**: 日付
   - **カテゴリ**: LINE運用 / LINEマーケティング / 広告運用 から選ぶ
   - **下書き**: チェック中は公開されない。完成したら外す
   - **本文**: マークダウンで書く（見出し・箇条書き・太字が使える）
3. 「保存」→ 記事が `src/content/blog/` に追加される
4. **公開**: 現状はデプロイが必要（下記）。トップのコラム欄・一覧・サイトマップには自動で並ぶ。

---

## 公開（デプロイ）について

**保存＝公開が有効になっている。** 管理画面で「保存」すると GitHub に記事がコミットされ、GitHub Actions が自動でVercelへデプロイ → **約1〜2分で本番サイトに反映**される。WordPressの「公開」と同じ感覚で使える。

- 反映状況は GitHub → Actions タブ（https://github.com/layrinc/company-brain/actions ）で確認できる。
- すぐ反映されない時は1〜2分待つ。それでも出なければレイに「layr-hpの反映確認して」と言う。

## サイト設定（WordPressの「カスタマイザー」相当）

管理画面の左メニュー「**サイト設定**」から、トップページの文言・数値・会社情報をフォームで編集できる。保存すると自動で本番に反映（約1〜2分）。

| メニュー | 編集できるもの |
|---|---|
| ① 基本設定 | 問い合わせメール／**LINE友だち追加URL**（入れると緑ボタンの飛び先がLINEになる）／フッター文 |
| ② ヒーロー | キャッチコピー・サブコピー・ボタン文言・チップ・数値チップ3個 |
| ③ 実績数値 | 「数字で見る」の3枚のカード（業種・数値・説明）＋【要編集】帯のON/OFF |
| ④ 支援実績 | CASE事例3件（課題・施策・Before/After・グラフの高さ）＋【要編集】帯のON/OFF |
| ⑤ お約束 | ○できること・×できないこと の各リスト |
| ⑥ 代表挨拶 | **代表写真のアップロード**・本文段落・署名 |
| ⑦ FAQ | Q&Aの追加・編集・削除 |
| ⑧ 会社概要 | 会社名・代表者・所在地・設立・事業内容 |

**実数値が入ったら**: ③と④の「【要編集】注意書きを表示する」をオフにすると、黄色い帯が消える。

データの実体は `src/data/*.json`。管理画面を使わずレイに「実績数値を〇〇に変えて」と言っても同じ場所が更新される（どちらでも可）。

## デザインを変えたいとき

文言・数値は上記「サイト設定」で。**レイアウト・色・余白などの見た目**はコードを触る。Claude Codeでレイに指示するのが早い（例:「ヘッダーの色を変えて」「サービス欄の見出しを大きく」）。デザインの正本は `src/styles/style.css`。
